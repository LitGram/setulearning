## 🌟 1. स्मार्ट गाइड प्रवेश: 10 सेकंड में अध्याय का सार (Overview & Strategy)

> **अध्यापक की सीधी सलाह:**  
> 4 अंकों का यह अध्याय बोर्ड परीक्षा में गणित का सबसे सरल और 100% स्कोरिंग अध्याय है। इसमें केवल 2 मुख्य प्रकार के प्रश्न बनते हैं:  
> 1. **मुख्य मान शाखा (Principal Value Branch):** $\sin^{-1}$, $\cos^{-1}$, $\tan^{-1}$ के ऋणात्मक मानों का मुख्य मान ज्ञात करना — जैसे $\cos^{-1}(-1/2) = \pi - \pi/3 = 2\pi/3$।  
> 2. **त्रिकोणमितीय प्रतिस्थापन द्वारा सरलतम रूप (Simplest Form):** $\tan^{-1}\left(\frac{\cos x - \sin x}{\cos x + \sin x}\right)$ अथवा $\tan^{-1}\left(\frac{x}{\sqrt{a^2 - x^2}}\right)$ जैसे मानक फलनों को सरल करना।  
> 3. **पूरक संबंध सूत्र:** $\sin^{-1} x + \cos^{-1} x = \pi/2$ तथा $\tan^{-1} x + \cot^{-1} x = \pi/2$।

## 🎯 3. स्मार्ट ट्रिक्स एवं गुरुमंत्र (Smart Tricks & Memory Mnemonics)

### 🎯 गुरुमंत्र 1: ऋणात्मक मानों के दो परिवार (Family 1 vs Family 2)
- **परिवार 1 (Odd Functions / सीधे '-' बाहर):**
  - $\sin^{-1}(-x) = \mathbf{-\sin^{-1} x}$
  - $\tan^{-1}(-x) = \mathbf{-\tan^{-1} x}$
  - $\text{cosec}^{-1}(-x) = \mathbf{-\text{cosec}^{-1} x}$
  *(याद रखें: **S-T-C** — यहाँ माइनस चिन्ह सीधे बाहर आ जाता है!)*

- **परिवार 2 ($\pi - \theta$ वाले / द्वितीय चतुर्थांश):**
  - $\cos^{-1}(-x) = \mathbf{\pi - \cos^{-1} x}$
  - $\sec^{-1}(-x) = \mathbf{\pi - \sec^{-1} x}$
  - $\cot^{-1}(-x) = \mathbf{\pi - \cot^{-1} x}$
  *(याद रखें: **C-S-C** — यहाँ माइनस हटने पर $\mathbf{\pi - \dots}$ आता है!)*

### 🎯 गुरुमंत्र 2: $\sin^{-1}(\sin\theta)$ की सीमा का ध्यान रखें
- $\sin^{-1}(\sin\theta) = \theta$ केवल तभी होता है जब $\theta \in [-\pi/2, \pi/2]$ हो!
- **उदाहरण:** $\sin^{-1}\left(\sin\frac{2\pi}{3}\right) \neq \frac{2\pi}{3}$ (क्योंकि $2\pi/3 = 120^\circ \notin [-90^\circ, 90^\circ]$)।
  - सही हल: $\sin^{-1}\left(\sin\left(\pi - \frac{\pi}{3}\right)\right) = \sin^{-1}\left(\sin\frac{\pi}{3}\right) = \mathbf{\frac{\pi}{3}}$।

### 🎯 गुरुमंत्र 3: त्रिकोणमितीय प्रतिस्थापन की मास्टर गाइड
- यदि व्यंजक में $\sqrt{a^2 - x^2}$ दिखे $\implies x = a\sin\theta$ (या $a\cos\theta$) प्रतिस्थापित करें।
- यदि व्यंजक में $\sqrt{a^2 + x^2}$ दिखे $\implies x = a\tan\theta$ (या $a\cot\theta$) प्रतिस्थापित करें।
- यदि व्यंजक में $\sqrt{x^2 - a^2}$ दिखे $\implies x = a\sec\theta$ (या $a\,\text{cosec}\,\theta$) प्रतिस्थापित करें।
- यदि व्यंजक में $\sqrt{\frac{a - x}{a + x}}$ या $\frac{a - x}{a + x}$ दिखे $\implies x = a\cos 2\theta$ प्रतिस्थापित करें।

## 🔬 4. बोर्ड परीक्षा के मुख्य प्रकार एवं विस्तृत हल किए गए मॉडल उदाहरण (Extensive Solved Models)

### प्रकार 1: मुख्य मान ज्ञात करना (1 अंक - वस्तुनिष्ठ / अतिलघु)
* **मॉडल उदाहरण 1:** निम्नलिखित के मुख्य मान ज्ञात कीजिए:  
  (i) $\sin^{-1}\left(-\frac{1}{2}\right)$  
  (ii) $\cos^{-1}\left(-\frac{1}{\sqrt{2}}\right)$  
  (iii) $\tan^{-1}(-\sqrt{3})$  
* **चरणबद्ध हल:**  
  1. **(i) $\sin^{-1}\left(-\frac{1}{2}\right)$:**  
     हम जानते हैं कि $\sin^{-1}(-x) = -\sin^{-1} x$ तथा मुख्य मान शाखा $[-\pi/2, \pi/2]$ है।  
     $$\sin^{-1}\left(-\frac{1}{2}\right) = -\sin^{-1}\left(\frac{1}{2}\right) = -\sin^{-1}\left(\sin\frac{\pi}{6}\right) = \mathbf{-\frac{\pi}{6}}$$  
  2. **(ii) $\cos^{-1}\left(-\frac{1}{\sqrt{2}}\right)$:**  
     हम जानते हैं कि $\cos^{-1}(-x) = \pi - \cos^{-1} x$ तथा मुख्य मान शाखा $[0, \pi]$ है।  
     $$\cos^{-1}\left(-\frac{1}{\sqrt{2}}\right) = \pi - \cos^{-1}\left(\frac{1}{\sqrt{2}}\right) = \pi - \frac{\pi}{4} = \mathbf{\frac{3\pi}{4}}$$  
  3. **(iii) $\tan^{-1}(-\sqrt{3})$:**  
     हम जानते हैं कि $\tan^{-1}(-x) = -\tan^{-1} x$ तथा मुख्य मान शाखा $(-\pi/2, \pi/2)$ है।  
     $$\tan^{-1}(-\sqrt{3}) = -\tan^{-1}(\sqrt{3}) = -\tan^{-1}\left(\tan\frac{\pi}{3}\right) = \mathbf{-\frac{\pi}{3}}$$

---

### प्रकार 2: संयुक्त प्रतिलोम फलनों का मान ज्ञात करना (2 अंक)
* **मॉडल उदाहरण 2:** मान ज्ञात कीजिए: $\tan^{-1}(1) + \cos^{-1}\left(-\frac{1}{2}\right) + \sin^{-1}\left(-\frac{1}{2}\right)$  
* **चरणबद्ध हल:**  
  1. **विधि 1 (प्रत्येक का व्यक्तिगत मान रखकर):**  
     - $\tan^{-1}(1) = \frac{\pi}{4}$  
     - $\cos^{-1}\left(-\frac{1}{2}\right) = \pi - \cos^{-1}\left(\frac{1}{2}\right) = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$  
     - $\sin^{-1}\left(-\frac{1}{2}\right) = -\sin^{-1}\left(\frac{1}{2}\right) = -\frac{\pi}{6}$  
     कुल मान $= \frac{\pi}{4} + \frac{2\pi}{3} - \frac{\pi}{6} = \frac{3\pi + 8\pi - 2\pi}{12} = \frac{9\pi}{12} = \mathbf{\frac{3\pi}{4}}$  
  2. **विधि 2 (स्मार्ट ट्रिक — पूरक सूत्र द्वारा):**  
     हम जानते हैं कि $\cos^{-1} x + \sin^{-1} x = \frac{\pi}{2}$ (जहाँ $x \in [-1, 1]$)।  
     यहाँ $x = -1/2$ दोनों में समान है:  
     $$\cos^{-1}\left(-\frac{1}{2}\right) + \sin^{-1}\left(-\frac{1}{2}\right) = \frac{\pi}{2}$$  
     अतः व्यंजक $= \tan^{-1}(1) + \frac{\pi}{2} = \frac{\pi}{4} + \frac{\pi}{2} = \mathbf{\frac{3\pi}{4}}$।  
  3. **उत्तर:** $\frac{3\pi}{4}$।

---

### प्रकार 3: प्रतिलोम फलन को सरलतम रूप में व्यक्त करना (2.5 अंक)
* **मॉडल उदाहरण 3:** $\tan^{-1}\left[\frac{\cos x - \sin x}{\cos x + \sin x}\right]$ को सरलतम रूप में लिखिए, जहाँ $\frac{-\pi}{4} < x < \frac{3\pi}{4}$।  
* **चरणबद्ध हल:**  
  1. दिए गए कोष्ठक के अंश व हर में $\cos x$ का भाग देने पर:  
     $$\frac{\cos x - \sin x}{\cos x + \sin x} = \frac{\frac{\cos x}{\cos x} - \frac{\sin x}{\cos x}}{\frac{\cos x}{\cos x} + \frac{\sin x}{\cos x}} = \frac{1 - \tan x}{1 + \tan x}$$  
  2. हम जानते हैं कि $1 = \tan\frac{\pi}{4}$ होता है:  
     $$\frac{1 - \tan x}{1 + 1 \cdot \tan x} = \frac{\tan\frac{\pi}{4} - \tan x}{1 + \tan\frac{\pi}{4}\tan x} = \tan\left(\frac{\pi}{4} - x\right)$$  
  3. अब प्रतिलोम फलन में मान रखने पर:  
     $$\tan^{-1}\left[\tan\left(\frac{\pi}{4} - x\right)\right] = \mathbf{\frac{\pi}{4} - x}$$  
  4. **उत्तर:** सरलतम रूप **$\frac{\pi}{4} - x$** है।

---

### प्रकार 4: बीजीय प्रतिस्थापन द्वारा सरलतम रूप (2.5 अंक)
* **मॉडल उदाहरण 4:** सरलतम रूप में लिखिए: $\tan^{-1}\left[\frac{x}{\sqrt{a^2 - x^2}}\right]$, जहाँ $|x| < a$।  
* **चरणबद्ध हल:**  
  1. व्यंजक में $\sqrt{a^2 - x^2}$ है, अतः माना $x = a\sin\theta \implies \sin\theta = \frac{x}{a} \implies \theta = \sin^{-1}\left(\frac{x}{a}\right)$  
  2. $x$ का मान प्रतिस्थापित करने पर:  
     $$\tan^{-1}\left[\frac{a\sin\theta}{\sqrt{a^2 - a^2\sin^2\theta}}\right] = \tan^{-1}\left[\frac{a\sin\theta}{\sqrt{a^2(1 - \sin^2\theta)}}\right]$$  
     $$= \tan^{-1}\left[\frac{a\sin\theta}{a\cos\theta}\right] = \tan^{-1}[\tan\theta] = \theta$$  
  3. $\theta$ का मान पुनः रखने पर:  
     $$\mathbf{= \sin^{-1}\left(\frac{x}{a}\right)}$$  
  4. **उत्तर:** $\sin^{-1}\left(\frac{x}{a}\right)$।

---

### प्रकार 5: समीकरण को हल करना (2.5 अंक)
* **मॉडल उदाहरण 5:** समीकरण को $x$ के लिए हल कीजिए: $\sin\left(\sin^{-1}\frac{1}{5} + \cos^{-1} x\right) = 1$  
* **चरणबद्ध हल:**  
  1. दिया है: $\sin\left(\sin^{-1}\frac{1}{5} + \cos^{-1} x\right) = 1$  
  2. दोनों पक्षों में $\sin^{-1}$ लेने पर:  
     $$\sin^{-1}\frac{1}{5} + \cos^{-1} x = \sin^{-1}(1)$$  
  3. $\sin^{-1}(1) = \frac{\pi}{2}$ रखने पर:  
     $$\sin^{-1}\frac{1}{5} + \cos^{-1} x = \frac{\pi}{2}$$  
  4. पूरक कोण प्रमेय से: $\sin^{-1} x + \cos^{-1} x = \frac{\pi}{2} \implies \cos^{-1} x = \frac{\pi}{2} - \sin^{-1} x$  
     अतः:  
     $$\sin^{-1}\frac{1}{5} = \frac{\pi}{2} - \cos^{-1} x = \sin^{-1} x$$  
  5. तुलना करने पर:  
     $$\mathbf{x = \frac{1}{5}}$$  
  6. **उत्तर:** $x = \frac{1}{5}$।

## 📝 6. बोर्ड-पैटर्न अभ्यास प्रश्न संग्रह (Selected Board Practice Bank)

1. **[Practice Question 1]** $\cos^{-1}\left(\cos\frac{7\pi}{6}\right)$ का मान ज्ञात कीजिए। (1 अंक)  
   *उत्तर:* $7\pi/6 \notin [0, \pi]$।  
   $\cos\frac{7\pi}{6} = \cos\left(2\pi - \frac{5\pi}{6}\right) = \cos\frac{5\pi}{6}$  
   चूँकि $\frac{5\pi}{6} \in [0, \pi]$, अतः $\cos^{-1}\left(\cos\frac{7\pi}{6}\right) = \cos^{-1}\left(\cos\frac{5\pi}{6}\right) = \mathbf{\frac{5\pi}{6}}$।
2. **[Practice Question 2]** $\tan^{-1}\left(\tan\frac{3\pi}{4}\right)$ का मान ज्ञात कीजिए। (1 अंक)  
   *उत्तर:* $3\pi/4 \notin (-\pi/2, \pi/2)$।  
   $\tan\frac{3\pi}{4} = \tan\left(\pi - \frac{\pi}{4}\right) = -\tan\frac{\pi}{4} = \tan\left(-\frac{\pi}{4}\right)$  
   अतः $\tan^{-1}\left(\tan\frac{3\pi}{4}\right) = \mathbf{-\frac{\pi}{4}}$।
3. **[Practice Question 3]** सिद्ध कीजिए कि $3\sin^{-1} x = \sin^{-1}(3x - 4x^3)$, जहाँ $x \in \left[-\frac{1}{2}, \frac{1}{2}\right]$। (1.5 अंक)  
   *उत्तर:* माना $x = \sin\theta \implies \theta = \sin^{-1} x$।  
   RHS $= \sin^{-1}(3\sin\theta - 4\sin^3\theta) = \sin^{-1}(\sin 3\theta) = 3\theta = 3\sin^{-1} x = \text{LHS}$। सिद्ध हुआ।
4. **[Practice Question 4]** यदि $\sin(\sin^{-1}\frac{3}{5} + \cos^{-1} x) = 1$ हो, तो $x$ का मान लिखिए। (1 अंक)  
   *उत्तर:* $\sin^{-1}\frac{3}{5} + \cos^{-1} x = \sin^{-1}(1) = \frac{\pi}{2} \implies \cos^{-1} x = \frac{\pi}{2} - \sin^{-1}\frac{3}{5} = \cos^{-1}\frac{3}{5} \implies \mathbf{x = \frac{3}{5}}$।
5. **[Practice Question 5]** $\cot(\tan^{-1} a + \cot^{-1} a)$ का मान ज्ञात कीजिए। (1 अंक)  
   *उत्तर:* हम जानते हैं कि $\tan^{-1} a + \cot^{-1} a = \frac{\pi}{2}$। अतः $\cot\left(\frac{\pi}{2}\right) = \mathbf{0}$।

## ⚡ 8. फटाफट 1-मिनट चीट शीट (Pre-Exam Rapid Cheat Sheet)

1. **मुख्य मान परिसर:** $\sin^{-1} \to [-\pi/2, \pi/2]$; $\cos^{-1} \to [0, \pi]$; $\tan^{-1} \to (-\pi/2, \pi/2)$; $\cot^{-1} \to (0, \pi)$।
2. **माइनस नियम 1:** $\sin^{-1}(-x) = -\sin^{-1} x$; $\tan^{-1}(-x) = -\tan^{-1} x$; $\text{cosec}^{-1}(-x) = -\text{cosec}^{-1} x$।
3. **माइनस नियम 2:** $\cos^{-1}(-x) = \pi - \cos^{-1} x$; $\cot^{-1}(-x) = \pi - \cot^{-1} x$; $\sec^{-1}(-x) = \pi - \sec^{-1} x$।
4. **पूरक संबंध ($\pi/2$):** $\sin^{-1} x + \cos^{-1} x = \pi/2$; $\tan^{-1} x + \cot^{-1} x = \pi/2$; $\sec^{-1} x + \text{cosec}^{-1} x = \pi/2$।
5. **व्युत्क्रम:** $\sin^{-1}(1/x) = \text{cosec}^{-1} x$; $\cos^{-1}(1/x) = \sec^{-1} x$; $\tan^{-1}(1/x) = \cot^{-1} x$ ($x > 0$)।
6. **सीमा नियम:** $\sin^{-1}(\sin\theta) = \theta$ केवल तभी जब $\theta \in [-\pi/2, \pi/2]$।
7. **मानक मान:** $\sin^{-1}(1/2) = \pi/6$; $\cos^{-1}(1/2) = \pi/3$; $\tan^{-1}(1) = \pi/4$; $\tan^{-1}(\sqrt{3}) = \pi/3$।
8. **प्रतिस्थापन:** $\sqrt{a^2-x^2} \implies x = a\sin\theta$; $\sqrt{a^2+x^2} \implies x = a\tan\theta$; $\sqrt{x^2-a^2} \implies x = a\sec\theta$।
9. **अंश-हर सूत्र:** $\frac{\cos x - \sin x}{\cos x + \sin x} = \tan(\pi/4 - x)$।

## 🔑 9. संपूर्ण व्याख्यात्मक उत्तर-कुंजी (Complete Explanatory Answer Key)

### खंड 'अ' MCQs हल:
* **Q1 का हल: (B)** $\sin^{-1}(-\sqrt{3}/2) = -\sin^{-1}(\sqrt{3}/2) = \mathbf{-\pi/3}$।
* **Q2 का हल: (D)** $13\pi/6 = 2\pi + \pi/6$। अतः $\cos(13\pi/6) = \cos(\pi/6)$। चूँकि $\pi/6 \in [0, \pi]$, अतः मान $= \mathbf{\pi/6}$।
* **Q3 का हल: (C)** $y = \cos^{-1} x$ का मुख्य मान परिसर **$[0, \pi]$** होता है।
* **Q4 का हल: (D)** $\sin^{-1}(-1/2) = -\pi/6$। अतः व्यंजक $= \sin(\pi/3 - (-\pi/6)) = \sin(\pi/3 + \pi/6) = \sin(\pi/2) = \mathbf{1}$।

### रिक्त स्थान हल:
1. **$\pi/2$**।
2. **$(-\pi/2, \pi/2)$**।
3. **$\pi - \cos^{-1} x$**।
4. **$\text{cosec}^{-1} x$**।

### अतिलघूत्तरात्मक हल:
1. **$\cot^{-1}(-1/\sqrt{3})$:** $\pi - \cot^{-1}(1/\sqrt{3}) = \pi - \pi/3 = \mathbf{2\pi/3}$।
2. **$\tan^{-1}\sqrt{3} - \sec^{-1}(-2)$:** $\frac{\pi}{3} - (\pi - \sec^{-1} 2) = \frac{\pi}{3} - (\pi - \frac{\pi}{3}) = \frac{\pi}{3} - \frac{2\pi}{3} = \mathbf{-\frac{\pi}{3}}$।
3. **$\sin^{-1} x$ का प्रांत:** **$[-1, 1]$**।
4. **$\sin^{-1}(\sin\frac{3\pi}{5})$:** $\sin(3\pi/5) = \sin(\pi - 2\pi/5) = \sin(2\pi/5)$। चूँकि $2\pi/5 = 72^\circ \in [-\pi/2, \pi/2]$, अतः मान $= \mathbf{2\pi/5}$।
