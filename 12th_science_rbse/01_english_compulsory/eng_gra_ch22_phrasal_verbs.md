## 🌟 1. Master High-Yield Phrasal Verbs (Alphabetical)

| Verb | Phrasal Verb | Hindi Meaning | English Meaning & Exam Sentence |
|---|---|---|---|
| **BREAK** | **Break down** | खराब होना / रो पड़ना | Stop functioning / lose control: *His car broke down on the highway.* |
| | **Break out** | अचानक फैलना | Spread suddenly (war/disease): *Cholera broke out in the village.* |
| | **Break into** | जबरन घुसना | Enter by force: *Thieves broke into the house.* |
| **BRING** | **Bring up** | पालन-पोषण करना | Rear/educate: *He was brought up by his aunt.* |
| | **Bring out** | प्रकाशित करना | Publish/reveal: *The publisher brought out a new book.* |
| **COME** | **Come across** | अचानक मिलना | Meet by chance: *I came across an old friend yesterday.* |
| | **Come off** | संपन्न होना | Take place successfully: *The wedding came off smoothly.* |
| **GET** | **Get along** | मित्रतापूर्ण संबंध | Be on good terms: *He gets along well with his neighbors.* |
| | **Get over** | उबरना / पार पाना | Overcome difficulty/illness: *She soon got over her grief.* |
| **GIVE** | **Give up** | त्याग देना / छोड़ना | Abandon a habit: *He gave up smoking.* |
| | **Give away** | बाँटना / वितरित करना | Distribute prizes: *The Chief Guest gave away the prizes.* |
| **PUT** | **Put out** | बुझाना | Extinguish fire: *Firefighters put out the fire.* |
| | **Put off** | स्थगित करना | Postpone: *The meeting was put off till next week.* |
| | **Put up with**| सहन करना | Tolerate: *I cannot put up with his rude behavior.* |
| **RUN** | **Run into** | कर्ज में डूबना / मिलना| Incur debt / meet: *He ran into heavy debts.* |
| | **Run over** | कुचल देना | Knock down by vehicle: *A dog was run over by a speeding truck.* |
| **TURN** | **Turn down** | अस्वीकार करना | Reject an offer: *She turned down his proposal.* |
| | **Turn up** | उपस्थित होना | Arrive/appear: *Only five students turned up today.* |
