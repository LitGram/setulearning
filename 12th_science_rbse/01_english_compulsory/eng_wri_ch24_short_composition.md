## 🌟 1. Standard Notice Format (Mandatory in a Box)

```
┌──────────────────────────────────────────────────────────────┐
│                NAME OF ISSUING INSTITUTION/SCHOOL            │
│                            PLACE                             │
│                                                              │
│ DATE: 15 October 2026                                        │
│                                                              │
│                           NOTICE                             │
│                    CATCHY TITLE / HEADING                    │
│                                                              │
│ This is to inform all the students that [Event Name] will    │
│ be organized on [Date] at [Time] in the [Venue]. Interested  │
│ students may submit their names to the undersigned latest    │
│ by [Last Date].                                              │
│                                                              │
│ For further details, please contact the undersigned.         │
│                                                              │
│ [Signature]                                                  │
│ [NAME]                                                       │
│ [Designation / Head Boy / Secretary]                         │
└──────────────────────────────────────────────────────────────┘
```

## 🌟 2. Formal Invitation Reply (Acceptance & Refusal)

- Written in **Third Person** (Mr. and Mrs. Sharma thank...).
- No salutation (Dear...) and no signature at the bottom.
- Clearly states date, time, venue, and unambiguous acceptance or refusal with a polite reason.
