## Section A: Vector Space and Matrices (Vector Space and Matrices)

### 1.1 What is a Vector Space? (Understanding Vector Space)

**In simple words:**  
In B.Sc. physics, a vector is an arrow. It has a direction and a length. Examples are displacement, velocity and force.  
In M.Sc. physics, especially in quantum mechanics, the wavefunction ψ of a particle also acts like a vector. Two wavefunctions can be added. Each one can also be multiplied by a number.

So a **Vector Space** (सदिश समष्टि) is any collection of objects (set V) that follows two rules: **vector addition (+)** and **scalar multiplication (·)**.

**Formal Definition:**  
A non-empty set V is a vector space over a field F (such as real numbers R or complex numbers C) if it follows these 8 rules (Axioms):

| S.No. | Name of the Axiom (नियम) | Mathematical Equation | Simple Physical Meaning |
| :--- | :--- | :--- | :--- |
| 1 | Closure under Addition | If u, v ∈ V, then u + v ∈ V | The sum of two valid states is also a valid state. |
| 2 | Associativity | (u + v) + w = u + (v + w) | You can add three vectors in any grouping. The total does not change. |
| 3 | Commutativity | u + v = v + u | The order of adding does not change the sum. |
| 4 | Additive Identity | There exists 0 ∈ V such that v + 0 = v | The space must have a zero (origin) vector. |
| 5 | Additive Inverse | v + (-v) = 0 | Every vector has an opposite vector. |
| 6 | Scalar Distribution Rule 1 | a(u + v) = au + av (a ∈ F) | Doubling the amplitude doubles every component. |
| 7 | Scalar Distribution Rule 2 | (a + b)v = av + bv | Adding numbers and then scaling works like scaling first. |
| 8 | Associativity and Identity Rule | (ab)v = a(bv) and 1·v = v | Multiplying by 1 changes nothing. |

**Vector Subspace (उपसमष्टि):**  
If V is a vector space, a non-empty subset W is a **Subspace** when W is also a vector space under the same operations.  
**Test for a subspace:** W is a subspace if and only if, for any u, v ∈ W and any a, b ∈ F:

> **a u + b v ∈ W**

So the set must stay closed under both addition and scalar multiplication. In short, a subspace never lets you escape: adding or scaling its members keeps you inside it.

**Solved Example 1 (Checking for Subspace):**  
**Question:** Is W = {(x, y, z) : 2x - y + 3z = 0} a subspace of R³?  
**Solution:**  
Let u = (x₁, y₁, z₁) and v = (x₂, y₂, z₂) be in W. So:  
2x₁ - y₁ + 3z₁ = 0   (Equation 1)  
2x₂ - y₂ + 3z₂ = 0   (Equation 2)  

Step 1: Write a u + b v:  
a u + b v = (a x₁ + b x₂,  a y₁ + b y₂,  a z₁ + b z₂)  

Step 2: Put these values in the equation:  
2(a x₁ + b x₂) - (a y₁ + b y₂) + 3(a z₁ + b z₂)  
= a (2x₁ - y₁ + 3z₁) + b (2x₂ - y₂ + 3z₂)  
= a (0) + b (0) = 0  

The condition holds, so W is a subspace of R³.

**Solved Example 2 (When it is not a subspace):**  
**Question:** Is W = {(x, y, z) : x + y + z = 1} a subspace of R³?  
**Solution:**  
Every subspace must contain the zero vector (0, 0, 0).  
Here 0 + 0 + 0 = 0, and 0 ≠ 1.  
So the zero vector is not in W. Therefore W is not a subspace.

**Linear Span L(S):**  
The linear span L(S) (or Span(S)) of a set S = {v₁, v₂, ..., v\_k} is the set of all linear combinations c₁v₁ + c₂v₂ + ... + c\_kv\_k. It is the smallest subspace that contains S.

### 1.2 Linear Independence, Basis and Dimension (Linear Independence & Basis)

**In simple words:**  
Stand in a room. Walk as far as you like towards East (x) and North (y). You still cannot go up towards the ceiling (z). So the upward direction is **independent** of East and North. This is **Linear Independence** (रैखिक स्वतंत्रता).

If a vector can be made by adding or scaling the other vectors, it gives no new direction. It is **Linearly Dependent** (रैखिक परतंत्र). Such a vector is an extra one. It does not add a new direction.

**Mathematical Definition:**  
A set {v₁, v₂, ..., v\_k} is linearly independent (LI) if this equation:

> **c₁ v₁ + c₂ v₂ + ... + c\_k v\_k = 0**

has only one solution: **c₁ = c₂ = ... = c\_k = 0**.  
If even one coefficient is non-zero (c\_i ≠ 0), the set is **linearly dependent (LD)**.

**Basis and Dimension:**
- **Basis (आधार):** The smallest independent set that can build the whole space. For 3D space, the standard basis is î = (1,0,0), ĵ = (0,1,0), k̂ = (0,0,1).
- **Dimension (विमा):** The number of vectors in a basis. The dimension of 3D space is 3. Dimension tells you how many independent directions a space has.

**Exam Shortcut (Determinant Method):**  
If three vectors are given in R³, make a 3×3 matrix with them and find its determinant:
- If |A| ≠ 0, the vectors are **LI** and form a basis.
- If |A| = 0, the vectors are **LD**.

**Why the determinant works:** A 3×3 determinant is zero exactly when the three rows (or columns) depend on each other. So a non-zero determinant means the three vectors reach every direction in R³. If you get zero, find one vector that is a combination of the other two, and say so in the answer. That short statement earns the marks for the reasoning.

**Solved Numerical 1 (Linear Independence Test in R³):**  
**Question:** Are v₁ = (1, 2, 1), v₂ = (2, 1, 0), v₃ = (1, -1, 2) linearly independent in R³?

**Solution:**  
Step 1: Put the three vectors as rows of a matrix:  

    |A| = | 1   2   1 |
          | 2   1  -1 |
          | 1   0   2 |

Step 2: Expand along the first row:  
|A| = 1 · [ 1×2 - (-1)×0 ] - 2 · [ 2×2 - (-1)×1 ] + 1 · [ 2×0 - 1×1 ]  
|A| = 1(2 - 0) - 2(4 + 1) + 1(0 - 1)  
|A| = 2 - 10 - 1 = -9  

Step 3: Since |A| = -9 ≠ 0, the only solution of c₁v₁ + c₂v₂ + c₃v₃ = 0 is c₁ = c₂ = c₃ = 0 (the trivial solution).  
**Conclusion:** The set is linearly independent (LI). It is a basis of R³.

**Solved Numerical 2 (Linear Dependence in Polynomial Space):**  
**Question:** Are p₁(x) = 1 + x, p₂(x) = x + x², p₃(x) = 1 + 2x + x² linearly independent?  
**Solution:**  
Step 1: Form the combination:  
c₁(1 + x) + c₂(x + x²) + c₃(1 + 2x + x²) = 0  

Step 2: Collect the terms with the same power of x:  
(c₁ + c₃)·1 + (c₁ + c₂ + 2c₃)·x + (c₂ + c₃)·x² = 0  

Step 3: Compare the coefficients:  
1. c₁ + c₃ = 0, so c₁ = -c₃  
2. c₂ + c₃ = 0, so c₂ = -c₃  
3. c₁ + c₂ + 2c₃ = (-c₃) + (-c₃) + 2c₃ = 0  

Step 4: Take c₃ = 1. Then c₁ = -1 and c₂ = -1.  
Check: -1·p₁ - 1·p₂ + 1·p₃ = -(1+x) - (x+x²) + (1+2x+x²) = 0.  
Some coefficients are non-zero, so the set is **linearly dependent (LD)**.

**Solved Numerical 3 (Basis and Dimension in R⁴):**  
**Question:** Find the dimension of the subspace spanned by v₁ = (1, 0, 1, 0), v₂ = (0, 1, 1, 1), v₃ = (1, 1, 2, 1).  
**Solution:**  
Step 1: Check whether v₃ depends on v₁ and v₂:  
v₁ + v₂ = (1+0, 0+1, 1+1, 0+1) = (1, 1, 2, 1) = v₃  
So v₃ is made from v₁ and v₂. It adds no new direction.  

Step 2: v₁ and v₂ are not multiples of each other, so {v₁, v₂} is independent.  
So the basis is {v₁, v₂}, and **Dimension = 2**.

**Exam note:** In R⁴, look first for a simple relation such as v₃ = v₁ + v₂. If one vector is a combination of the others, you can drop it at once. This saves a full determinant or row-reduction calculation.

### 1.3 Inner Product Space and Cauchy-Schwarz Inequality (Inner Product Space)

**In simple words:**  
In B.Sc., the dot product is A · B = |A||B| cos θ. It gives two things:
1. The length of a vector: |A|² = A · A
2. The angle between two vectors: cos θ = (A · B) / (|A||B|)

The **Inner Product** (आंतरिक गुणनफल) is a general form of the dot product. It also works for functions and quantum wavefunctions. In quantum mechanics, the bra-ket &lt;ψ|φ&gt; is an inner product of two states.

**4 Basic Rules (Axioms) of Inner Product:**
1. Conjugate symmetry: &lt;u, v&gt; = &lt;v, u&gt;\*
2. Linear in the first part: &lt;a u₁ + b u₂, v&gt; = a &lt;u₁, v&gt; + b &lt;u₂, v&gt;
3. Positive: &lt;v, v&gt; ≥ 0
4. Non-degenerate: &lt;v, v&gt; = 0 only if v = 0

**Norm (मानक) / Length:**  
The norm of a vector v is:

> **||v|| = √(&lt;v, v&gt;)**

**Cauchy-Schwarz Inequality:**  
**Statement:** For any two vectors u and v in an inner product space:

> **|&lt;u, v&gt;| ≤ ||u|| · ||v||**

(Squared form: |&lt;u, v&gt;|² ≤ &lt;u, u&gt; · &lt;v, v&gt;)

**Physical meaning:** The overlap of two states can never be more than the product of their lengths. This is because cos θ ≤ 1. The Heisenberg Uncertainty Principle (Δx · Δp ≥ ħ/2) comes directly from this inequality. In short, the overlap of two states can never be larger than the product of their lengths.

**Short Proof (Exam Steps):**  
Step 1: Let λ be any real number. Since the inner product is positive:  
&lt;u - λv, u - λv&gt; ≥ 0  

Step 2: Expand:  
&lt;u, u&gt; - λ &lt;u, v&gt; - λ &lt;v, u&gt; + λ² &lt;v, v&gt; ≥ 0  
If u and v are real, &lt;u, v&gt; = &lt;v, u&gt;:  
||u||² - 2λ &lt;u, v&gt; + λ² ||v||² ≥ 0  

Step 3: This is a quadratic in λ: Aλ² + Bλ + C ≥ 0, where A = ||v||², B = -2&lt;u, v&gt;, C = ||u||².  
A quadratic that is never negative must have discriminant B² - 4AC ≤ 0:  
(-2 &lt;u, v&gt;)² - 4 (||v||²)(||u||²) ≤ 0  
4 |&lt;u, v&gt;|² ≤ 4 ||u||² ||v||²  
|&lt;u, v&gt;|² ≤ ||u||² ||v||²  

Step 4: Take the square root:  
|&lt;u, v&gt;| ≤ ||u|| ||v||  (Hence proved)

**Why this proof is accepted in exams:** It uses only the positivity axiom and the discriminant of a quadratic. It does not need any picture of angles. So the same proof works for vectors, functions, polynomials and quantum states alike.

**Triangle Inequality:**  
Using Cauchy-Schwarz, we can prove: ||u + v|| ≤ ||u|| + ||v||  
Proof:  
||u + v||² = &lt;u + v, u + v&gt; = &lt;u, u&gt; + &lt;u, v&gt; + &lt;v, u&gt; + &lt;v, v&gt;  
= ||u||² + 2 Re&lt;u, v&gt; + ||v||²  
≤ ||u||² + 2 |&lt;u, v&gt;| + ||v||²  
Using |&lt;u, v&gt;| ≤ ||u|| ||v||:  
||u + v||² ≤ ||u||² + 2 ||u|| ||v|| + ||v||² = (||u|| + ||v||)²  
Taking the square root: **||u + v|| ≤ ||u|| + ||v||** (Hence proved)

**Solved Numerical (Angle in Function Space):**  
**Question:** Find the angle θ between f(x) = x and g(x) = x² on [0, 1], where &lt;f, g&gt; = ∫₀¹ f(x) g(x) dx.  
**Solution:**  
1. Inner product:  
   &lt;f, g&gt; = ∫₀¹ x · x² dx = ∫₀¹ x³ dx = [ x⁴ / 4 ]₀¹ = 1/4  
2. Norm of f:  
   ||f||² = &lt;f, f&gt; = ∫₀¹ x² dx = [ x³ / 3 ]₀¹ = 1/3, so ||f|| = 1/√3  
3. Norm of g:  
   ||g||² = &lt;g, g&gt; = ∫₀¹ x⁴ dx = [ x⁵ / 5 ]₀¹ = 1/5, so ||g|| = 1/√5  
4. Angle:  
   cos θ = &lt;f, g&gt; / (||f|| · ||g||) = (1/4) / [ (1/√3)(1/√5) ] = (1/4) / (1/√15) = √15 / 4  
   So **θ = cos⁻¹(√15 / 4)**

### 1.4 Gram-Schmidt Orthogonalization (ग्राम-श्मिट विधि)

**In simple words:**  
You are given independent vectors, but they are not at 90 degrees to each other. Their lengths are also not 1. Gram-Schmidt changes them into a set of **orthonormal** vectors. Think of it as straightening a skewed set of rulers into perpendicular rulers, each of length 1. Orthonormal means they are perpendicular (Orthogonal) and each has length 1 (Normalized).

**Step-by-Step Method:**

> **Step 1:** u₁ = v₁, and e₁ = u₁ / ||u₁||  
> **Step 2:** u₂ = v₂ - [ &lt;v₂, u₁&gt; / &lt;u₁, u₁&gt; ] · u₁, and e₂ = u₂ / ||u₂||  
> **Step 3:** u₃ = v₃ - [ &lt;v₃, u₁&gt; / &lt;u₁, u₁&gt; ] · u₁ - [ &lt;v₃, u₂&gt; / &lt;u₂, u₂&gt; ] · u₂, and e₃ = u₃ / ||u₃||

**Solved Numerical 1 (2 Vectors in R³):**  
**Question:** Make an orthonormal set {e₁, e₂} from v₁ = (1, 0, 1) and v₂ = (1, 2, 0).

**Solution:**  
**Step 1: Find u₁ and e₁:**  
u₁ = v₁ = (1, 0, 1)  
&lt;u₁, u₁&gt; = 1² + 0² + 1² = 2  
Length: ||u₁|| = √2  
**e₁ = u₁ / ||u₁|| = (1/√2, 0, 1/√2)**

**Step 2: Find u₂:**  
Dot product: &lt;v₂, u₁&gt; = (1)(1) + (2)(0) + (0)(1) = 1  
u₂ = (1, 2, 0) - (1 / 2) · (1, 0, 1)  
u₂ = (1 - 1/2,  2 - 0,  0 - 1/2) = (1/2, 2, -1/2)

**Step 3: Find e₂:**  
&lt;u₂, u₂&gt; = (1/2)² + 2² + (-1/2)² = 1/4 + 4 + 1/4 = 9/2  
Length: ||u₂|| = √(9/2) = 3 / √2  
**e₂ = u₂ / ||u₂|| = ( 1/(3√2),  (2√2)/3,  -1/(3√2) )**

**Check (Orthogonality):**  
&lt;e₁, e₂&gt; = (1/√2)(1/(3√2)) + 0 + (1/√2)(-1/(3√2)) = 1/6 - 1/6 = 0  
So the two vectors are perpendicular, and each has length 1.

**Solved Numerical 2 (Complete Solution for 3 Vectors in R³):**  
**Question:** Make an orthogonal basis {u₁, u₂, u₃} from v₁ = (0, 1, 1), v₂ = (1, 0, 1), v₃ = (1, 1, 0).

**Solution:**  
**Step 1: u₁:**  
u₁ = v₁ = (0, 1, 1)  
&lt;u₁, u₁&gt; = 0² + 1² + 1² = 2

**Step 2: u₂:**  
&lt;v₂, u₁&gt; = (1)(0) + (0)(1) + (1)(1) = 1  
u₂ = v₂ - [ &lt;v₂, u₁&gt; / &lt;u₁, u₁&gt; ] u₁  
u₂ = (1, 0, 1) - (1/2)(0, 1, 1) = (1, -1/2, 1/2)  
Multiply by 2 to make it simple: u₂ = (2, -1, 1)  
&lt;u₂, u₂&gt; = 2² + (-1)² + 1² = 6

**Step 3: u₃:**  
&lt;v₃, u₁&gt; = (1)(0) + (1)(1) + (0)(1) = 1  
&lt;v₃, u₂&gt; = (1)(2) + (1)(-1) + (0)(1) = 1  
u₃ = v₃ - [ &lt;v₃, u₁&gt; / &lt;u₁, u₁&gt; ] u₁ - [ &lt;v₃, u₂&gt; / &lt;u₂, u₂&gt; ] u₂  
u₃ = (1, 1, 0) - (1/2)(0, 1, 1) - (1/6)(2, -1, 1)  
Component by component:  
- x-component: 1 - 0 - 2/6 = 2/3  
- y-component: 1 - 1/2 - (-1/6) = 2/3  
- z-component: 0 - 1/2 - 1/6 = -2/3  

So u₃ = (2/3, 2/3, -2/3). Multiply by 3/2: u₃ = (1, 1, -1).  
**Check:**  
&lt;u₁, u₃&gt; = 0 + 1 - 1 = 0  
&lt;u₂, u₃&gt; = 2 - 1 - 1 = 0  
So the set { (0, 1, 1), (2, -1, 1), (1, 1, -1) } is orthogonal.

**Solved Numerical 3 (Orthogonal Polynomials, Legendre type):**  
**Question:** Find the first 3 orthogonal polynomials from {1, x, x²} on [-1, 1], where &lt;f, g&gt; = ∫\_(-1)¹ f(x) g(x) dx.  
**Solution:**  
Let v₀ = 1, v₁ = x, v₂ = x².

**Step 1:**  
u₀ = 1  
&lt;u₀, u₀&gt; = ∫\_(-1)¹ 1 dx = 2

**Step 2:**  
&lt;v₁, u₀&gt; = ∫\_(-1)¹ x dx = 0 (an odd function on a symmetric interval gives 0).  
So u₁ = x - 0 = x  
&lt;u₁, u₁&gt; = ∫\_(-1)¹ x² dx = 2/3

**Step 3:**  
&lt;v₂, u₀&gt; = ∫\_(-1)¹ x² dx = 2/3  
&lt;v₂, u₁&gt; = ∫\_(-1)¹ x³ dx = 0 (odd function)  
u₂ = x² - [ (2/3) / 2 ] · 1 - 0 = x² - 1/3  
Multiply by 3/2: (3x² - 1)/2.  
These are the Legendre polynomials, which you will meet again in Unit 2. Here they come straight from Gram-Schmidt, so you can see where they come from. Legendre polynomials are orthogonal on [-1, 1] with weight 1. The results are **P₀(x) = 1, P₁(x) = x, P₂(x) = (3x² - 1)/2**.

### 1.5 Linear Transformation and Rank-Nullity Theorem (Linear Transformation)

**In simple words:**  
A **Linear Transformation** T is an operation (like rotating a vector or scaling it) that follows two rules:
1. T(u + v) = T(u) + T(v)
2. T(c u) = c T(u)

In quantum mechanics, every measurement operator, such as the momentum operator p = -iħ d/dx or the Hamiltonian H, is a linear transformation.

**Kernel and Range:**
- **Kernel (Null Space):** All vectors v that T sends to zero: Ker(T) = {v ∈ V : T(v) = 0}. Its dimension is the **Nullity**.
- **Range (Image):** All outputs T(v): Range(T) = {T(v) : v ∈ V}. Its dimension is the **Rank**.

**Sylvester's Rank-Nullity Theorem:**  
If V is finite-dimensional and T: V → W is linear, then:

> **Rank(T) + Nullity(T) = dim(V)**

**Simple meaning:** The total dimension of the input is shared between what T keeps (Rank) and what T sends to zero (Nullity). So in any problem, check that Rank + Nullity equals the dimension of the starting space.

**Solved Example (Matrix of the Derivative Operator):**  
**Question:** Find the matrix of D = d/dx on quadratic polynomials P₂(x) with basis B = {1, x, x²}. Verify rank and nullity.  
**Solution:**  
Apply D to each basis vector:  
1. D(1) = 0 = 0·1 + 0·x + 0·x²  (Column 1: [0, 0, 0])  
2. D(x) = 1 = 1·1 + 0·x + 0·x²  (Column 2: [1, 0, 0])  
3. D(x²) = 2x = 0·1 + 2·x + 0·x²  (Column 3: [0, 2, 0])  

So the matrix is:  
A = [ [0, 1, 0],  
      [0, 0, 2],  
      [0, 0, 0] ]

- Kernel: Polynomials with derivative 0. These are the constants c·1. So Nullity = 1.  
- Range: After differentiating, we get polynomials of degree at most 1, with basis {1, x}. So Rank = 2.  
Check: Rank + Nullity = 2 + 1 = 3 = dim(P₂). (Verified)

### 1.6 Eigenvalue and Eigenvector (आइगेनवैल्यू और आइगेनवेक्टर)

**In simple words:**  
When a matrix A acts on a vector X, the vector usually changes direction. But some special vectors keep their direction. Only their length changes, by a factor λ:

> **A X = λ X**

- The special vector X is an **Eigenvector** (आइगेनवेक्टर). It is a special direction of the matrix. The matrix does not turn it. It only stretches or shrinks it.
- The factor λ is an **Eigenvalue** (आइगेनवैल्यू).
- In quantum physics, when we measure a quantity, the result is an eigenvalue of its operator. For example, measured energy levels are eigenvalues of the Hamiltonian.

**Characteristic Equation:**

> **det(A - λ I) = 0**

**2 Quick Tricks:**
1. **Trace Trick:** Sum of all eigenvalues = sum of the diagonal elements (Trace).
2. **Determinant Trick:** Product of all eigenvalues = determinant of the matrix.

**Cayley-Hamilton Theorem:**  
Every square matrix satisfies its own characteristic equation.  
If the equation is λ² - c₁λ + c₀ = 0, then A² - c₁A + c₀I = 0.  
We use this to find A⁻¹ and higher powers of A (like A³, A⁴). This saves work, because you do not need to multiply the matrix many times by itself.

**Solved Numerical 1 (2×2 Matrix):**  
**Question:** Find all eigenvalues and eigenvectors of A = [ [4, 1], [2, 3] ].

**Solution:**  
**Step 1: Characteristic equation:**  
| 4 - λ     1   | = 0  
|   2     3 - λ |  
(4 - λ)(3 - λ) - (2)(1) = 0  
12 - 7λ + λ² - 2 = 0  
λ² - 7λ + 10 = 0  
(λ - 5)(λ - 2) = 0  
So **λ₁ = 5, λ₂ = 2**  
(Check: 5 + 2 = 7 = 4 + 3 (trace). 5 × 2 = 10 = determinant (12 - 2 = 10). Correct.)

**Step 2: Eigenvector for λ₁ = 5:**  
Solve (A - 5I) X₁ = 0:  
[ [-1, 1], [2, -2] ] [ [x₁], [x₂] ] = [ [0], [0] ]  
Equation: -x₁ + x₂ = 0, so x₁ = x₂.  
Take x₁ = 1, then x₂ = 1.  
**X₁ = [ [1], [1] ]**

**Step 3: Eigenvector for λ₂ = 2:**  
Solve (A - 2I) X₂ = 0:  
[ [2, 1], [2, 1] ] [ [x₁], [x₂] ] = [ [0], [0] ]  
Equation: 2x₁ + x₂ = 0, so x₂ = -2x₁.  
Take x₁ = 1, then x₂ = -2.  
**X₂ = [ [1], [-2] ]**

**Check:** Multiply A by X₂. We get A X₂ = [4·1 + 1·(-2), 2·1 + 3·(-2)] = [2, -4] = 2 · [1, -2] = 2 X₂. The check works. Always check an eigenvector by multiplying it back into the matrix.

---

**Solved Numerical 2 (3×3 Matrix, favourite in exams):**  
**Question:** Find the eigenvalues of A = [ [1, 0, 0], [0, 2, 1], [0, 1, 2] ].

**Solution:**  
Step 1: Write |A - λI| = 0. Expand along the first row:  
(1 - λ) [ (2 - λ)² - 1 ] = 0  
(1 - λ) [ λ² - 4λ + 3 ] = 0  
(1 - λ)(λ - 1)(λ - 3) = 0  

So **λ = 1, 1, 3**.

**Exam note:** A repeated eigenvalue, such as λ = 1 appearing twice, needs extra care. Before you say the matrix can be diagonalized, count the independent eigenvectors for that value. Section 1.15 shows this count in full.

**Solved Numerical 3 (Finding A⁻¹ with Cayley-Hamilton):**  
**Question:** Verify Cayley-Hamilton for A = [ [1, 2], [3, 4] ] and find A⁻¹.  
**Solution:**  
Step 1: Characteristic equation:  
(1 - λ)(4 - λ) - 6 = λ² - 5λ - 2 = 0  
By Cayley-Hamilton: A² - 5A - 2I = 0  

Step 2: Verify:  
A² = [ [7, 10], [15, 22] ]  
5A = [ [5, 10], [15, 20] ], and 2I = [ [2, 0], [0, 2] ]  
A² - 5A - 2I = [ [7-5-2, 10-10-0], [15-15-0, 22-20-2] ] = [ [0, 0], [0, 0] ]. (Verified)  

Step 3: Find A⁻¹. Multiply A² - 5A - 2I = 0 by A⁻¹:  
A - 5I - 2A⁻¹ = 0, so 2A⁻¹ = A - 5I  
A⁻¹ = (1/2) [ [1-5, 2], [3, 4-5] ] = (1/2) [ [-4, 2], [3, -1] ]  
**A⁻¹ = [ [-2, 1], [3/2, -1/2] ]**

### 1.7 Diagonalization (विकर्णन)

**In simple words:**  
Many matrices have numbers all over the place. This makes calculation hard. **Diagonalization** means changing to new axes where only the main diagonal has numbers, and all other entries are zero. The diagonal numbers are the eigenvalues. Diagonal matrices are easy to raise to powers. For example, Dⁿ only needs each diagonal entry raised to the power n.

**Procedure:**
1. Find all eigenvalues λ₁, λ₂, ..., λₙ of A.
2. Find the eigenvectors X₁, X₂, ..., Xₙ.
3. Put them as columns to form the **Modal Matrix** P = [ X₁  X₂  ...  Xₙ ].
4. Then:

> **D = P⁻¹ A P = Diag(λ₁, λ₂, ..., λₙ)**

### 1.8 Hermitian, Unitary and Orthogonal Matrix (Special Matrices)

These three matrices are the most important in physics.

| Matrix Type | Condition | Key Properties | Physical Meaning |
| :--- | :--- | :--- | :--- |
| **Hermitian** | A† = (A\*)ᵀ = A | All eigenvalues are real. | Measured quantities (energy, momentum) are real. So their operators are Hermitian. |
| **Unitary** | A† A = I (A⁻¹ = A†) | \|λ\| = 1 for every eigenvalue. Length of a vector is kept. | Time evolution operator. Total probability stays 1. |
| **Orthogonal** | Aᵀ A = I (A⁻¹ = Aᵀ) | det(A) = ±1. Keeps distances and angles in a real plane. | Rotation of rigid bodies (rotation matrix). |

**Why these three types matter:** Physics needs measured values that are real, so observables are described by Hermitian operators. Time evolution must keep the total probability equal to 1, so it is unitary. Rotations in real space keep lengths, so they are orthogonal. Keep these three links in mind. Many exam questions start from them.

**Pauli Spin Matrices (पाउली स्पिन मैट्रिक्स):**  
These three matrices describe the spin 1/2 of an electron:

> **σₓ = [ [0, 1], [1, 0] ]**  
> **σᵧ = [ [0, -i], [i, 0] ]**  
> **σ\_z = [ [1, 0], [0, -1] ]**

**Important properties:**  
1. All three are Hermitian (σᵢ† = σᵢ) and unitary (σᵢ† σᵢ = I).  
2. σ\_x² = σ\_y² = σ\_z² = I.  
3. Trace(σᵢ) = 0.  
4. det(σᵢ) = -1.  
5. Anticommutation: σₓ σᵧ + σᵧ σₓ = 0. In short, {σᵢ, σⱼ} = 2 δᵢⱼ I.

**Theory Derivation 1 (High-Yield in exams):** Prove that all eigenvalues of a Hermitian matrix are real.  
**Proof:**  
Step 1: Let A be Hermitian (A† = A). Let X be an eigenvector with eigenvalue λ:  
A X = λ X   (Equation 1)  

Step 2: Multiply Equation 1 from the left by X†:  
X† A X = λ X† X   (Equation 2)  

Step 3: Take the dagger of Equation 1:  
X† A† = λ\* X†  
Since A† = A:  
X† A = λ\* X†  

Step 4: Multiply from the right by X:  
X† A X = λ\* X† X   (Equation 3)  

Step 5: The left sides of Equations 2 and 3 are the same. So:  
λ X† X = λ\* X† X  
(λ - λ\*)(X† X) = 0  

Step 6: X is not zero, so X† X = ||X||² ≠ 0. Therefore:  
λ - λ\* = 0, so **λ = λ***  
A number equal to its own conjugate is real. (Hence proved) Exam tip: this proof is short. Write each step with its reason, and you get credit for the logic.

**Theory Derivation 2:** Prove that eigenvectors of a Hermitian matrix with different eigenvalues are orthogonal.  
**Proof:**  
Let A X₁ = λ₁ X₁ and A X₂ = λ₂ X₂, with λ₁ ≠ λ₂.  
X₂† A X₁ = λ₁ X₂† X₁   (Equation 1)  
Take the dagger of the second equation. Since A† = A and λ₂ is real: X₂† A = λ₂ X₂†. Multiply by X₁:  
X₂† A X₁ = λ₂ X₂† X₁   (Equation 2)  

Subtract Equation 2 from Equation 1:  
(λ₁ - λ₂)(X₂† X₁) = 0  
Since λ₁ ≠ λ₂, we must have **X₂† X₁ = 0**.  
So the two eigenvectors are orthogonal. (Hence proved)

### 1.9 Complete Orthonormal Set (Complete Orthonormal Set of Functions)

**Definition:**  
A set of functions {ϕₙ(x)} is **orthonormal** on [a, b] if:

> **∫\_a^b ϕₘ\* (x) ϕₙ(x) dx = δₘₙ**

Here δₘₙ is the Kronecker delta. It is 1 when m = n, and 0 when m ≠ n.

**Completeness (पूर्णता):**  
The set is **complete** if any function f(x) on that interval can be written as a sum of these functions:

> **f(x) = Σ cₙ ϕₙ(x), where cₙ = ∫\_a^b ϕₙ\* (x) f(x) dx**

**Closure Relation:** Σₙ ϕₙ\* (x') ϕₙ(x) = δ(x - x') (Dirac delta function).

## Part B: Complex Variables

### 1.10 Analytic Functions & C-R Equations (Analytic Functions & C-R Equations)

**In simple words:**  
On the real line, we can come to a point x from two sides only: left or right. In the complex plane (z = x + iy), we can come to a point z₀ from infinitely many directions. So the derivative of f(z) exists only if it has the same value from every direction. In short, the function must be smooth and have one clear slope at each point. Such a smooth function is called an **Analytic Function** (विश्लेषिक फलन).

**Cauchy-Riemann (C-R) Equations:**  
Let f(z) = u(x, y) + i v(x, y).  
f(z) is analytic if the first partial derivatives of u and v are continuous and satisfy the C-R equations.

**Cartesian Form:**

> **∂u/∂x = ∂v/∂y  and  ∂u/∂y = - ∂v/∂x**  
> (Short form: u\_x = v\_y and u\_y = - v\_x)

**Polar Form, z = r e^(iθ):**

> **∂u/∂r = (1/r) ∂v/∂θ  and  ∂v/∂r = - (1/r) ∂u/∂θ**

**Derivation of Polar C-R Equations (Short Exam Proof):**  
We know x = r cos θ and y = r sin θ.  
By the chain rule:  
∂u/∂r = u\_x cos θ + u\_y sin θ  
∂u/∂θ = - u\_x r sin θ + u\_y r cos θ  
Similarly for v:  
∂v/∂r = v\_x cos θ + v\_y sin θ  
∂v/∂θ = - v\_x r sin θ + v\_y r cos θ  

Now use the Cartesian C-R equations, u\_x = v\_y and u\_y = -v\_x:  
∂v/∂θ = - (-u\_y) r sin θ + u\_x r cos θ = r (u\_x cos θ + u\_y sin θ) = r (∂u/∂r)  
So **∂u/∂r = (1/r) ∂v/∂θ**.  
The second equation, **∂v/∂r = - (1/r) ∂u/∂θ**, is found in the same way. (Hence proved)

**Harmonic Functions and Orthogonal Trajectories:**  
If f(z) = u + iv is analytic, the curves u(x, y) = c₁ and v(x, y) = c₂ always cut each other at 90 degrees.  
Proof:  
Slope of u = c₁: m₁ = - u\_x / u\_y  
Slope of v = c₂: m₂ = - v\_x / v\_y  
Product: m₁ · m₂ = (u\_x · v\_x) / (u\_y · v\_y)  
Using u\_x = v\_y and u\_y = - v\_x:  
m₁ · m₂ = (v\_y · v\_x) / (- v\_x · v\_y) = - 1  
So the two families of curves are perpendicular. In physics, if u gives equipotential lines, then v gives electric field lines.

**Exam use:** This orthogonality result is often asked as a short question. Write the slope product, then substitute the C-R equations. That gives the full proof in about four lines.

**Milne-Thomson Method (Find f(z) from u):**  
If only the real part u(x, y) is known, we can find f(z) without finding v:

> **f'(z) = u\_x(z, 0) - i u\_y(z, 0)**  
> **f(z) = ∫ [ u\_x(z, 0) - i u\_y(z, 0) ] dz + c**

**Solved Numerical (Milne-Thomson Method):**  
**Question:** If u(x, y) = x³ - 3xy² + 3x² - 3y², find the analytic function f(z).  
**Solution:**  
Step 1: Find the partial derivatives:  
u\_x = 3x² - 3y² + 6x  
u\_y = - 6xy - 6y  

Step 2: Put x = z and y = 0:  
u\_x(z, 0) = 3z² + 6z  
u\_y(z, 0) = 0  

Step 3: Use the Milne-Thomson formula:  
f'(z) = 3z² + 6z - i(0) = 3z² + 6z  

Step 4: Integrate:  
f(z) = ∫ (3z² + 6z) dz + c = z³ + 3z² + c  
**Answer: f(z) = z³ + 3z² + c**

### 1.11 Cauchy's Theorem and Formula (Cauchy's Theorem and Formula)

#### 1. Cauchy's Integral Theorem (कॉची समाकल प्रमेय)
**Statement:** If f(z) is analytic inside and on a simple closed curve (closed contour) C, then:

> **∮\_C f(z) dz = 0**

**Simple understanding:** This is like the loop integral ∮ E · dr = 0 for a conservative field. If there is no singular point inside the loop, the total loop integral is zero. The result depends only on the singular points inside the loop, not on the shape of the path.

#### 2. Cauchy's Integral Formula (कॉची समाकल सूत्र)
**Statement:** If z₀ lies inside a closed curve C, where the denominator becomes zero, then the value of f at z₀ is:

> **∮\_C [ f(z) / (z - z₀) ] dz = 2π i · f(z₀)**

**Formula for Higher Derivatives:**

> **∮\_C [ f(z) / (z - z₀)^(n+1) ] dz = [ 2π i / n! ] · f^(n)(z₀)**

**Solved Numerical 1:**  
**Question:** Evaluate I = ∮\_C [ e^(2z) / (z - 1)² ] dz, where C is the circle |z| = 2.  
**Solution:**  
Step 1: Find the singular point. (z - 1)² = 0 gives z = 1, a pole of order 2.  
Step 2: The circle |z| = 2 has radius 2. The point z₀ = 1 is inside.  
Step 3: Use the higher derivative formula with n + 1 = 2, so n = 1.  
Here f(z) = e^(2z), so f'(z) = 2 e^(2z), and f'(1) = 2 e².  
Step 4: I = 2π i · (2 e²) = **4π i e²**

**Check the logic:** The singular point z = 1 is inside |z| = 2, so its residue counts. If the point had been outside the circle, the answer would have been 0 by Cauchy's theorem. Always decide "inside or outside" before you calculate anything.

**Solved Numerical 2 (When the point is outside):**  
**Question:** Evaluate ∮\_C [ z² / (z - 3) ] dz, where C is the circle |z| = 1.  
**Solution:**  
The singular point is z = 3. The circle |z| = 1 has radius 1. So z = 3 is outside the circle.  
Then f(z) = z² / (z - 3) is analytic inside and on C.  
By Cauchy's Integral Theorem:  
**∮\_C [ z² / (z - 3) ] dz = 0**

### 1.12 Types of Singularities (विचित्रता के प्रकार)

A **singularity** is a point where the function is not analytic. It becomes infinite or undefined there. Quick test: a pole has only a finite number of negative powers. An essential singularity has infinitely many. There are three types:

1. **Removable Singularity:**  
   The limit exists and is finite. The Laurent series has no negative powers of 1/(z - z₀).  
   *Example:* f(z) = (sin z)/z at z = 0. Since lim (sin z)/z = 1 (finite), z = 0 is a removable singularity.

2. **Pole of Order m:**  
   The principal part has only m negative powers of (z - z₀), with the last term b\_m / (z - z₀)^m.  
   - If m = 1, it is a **Simple Pole**.  
   *Example:* f(z) = 1/(z - 2) has a simple pole at z = 2. f(z) = 1/(z - 1)³ has a pole of order 3 at z = 1.

3. **Essential Singularity:**  
   The principal part has infinitely many negative powers of (z - z₀).  
   *Example:* f(z) = e^(1/z) = 1 + 1/z + 1/(2! z²) + 1/(3! z³) + ... has an essential singularity at z = 0.

### 1.13 Taylor and Laurent Series (टेलर और लॉरेंट श्रेणी)

**In simple words:**  
If a function is smooth (analytic) at a point, we expand it in a **Taylor series**. If there is a pole at that point, the Taylor series does not work. Then we use the **Laurent series**. It has negative powers such as 1/z and 1/z² along with positive powers. Note: the expansion depends on the region. The same function gives different series in different rings (annuli).

**Laurent Series:**

> **f(z) = Σ\_(n=0)^∞ aₙ (z - z₀)ⁿ + Σ\_(n=1)^∞ bₙ / (z - z₀)ⁿ**  
> (Analytic part: the Taylor part. Principal part: the negative powers.)

**Solved Numerical (Common MGSU exam question):**  
**Question:** Find the Laurent expansion of f(z) = 1 / [(z - 1)(z - 2)] about z = 0 for:  
(i) the annulus 1 &lt; |z| &lt; 2  
(ii) |z| &gt; 2  

**Solution:**  
Step 1: Partial fractions:  
f(z) = 1 / (z - 2) - 1 / (z - 1)

**(i) Region 1 &lt; |z| &lt; 2:**  
- Here |z| &gt; 1, so |1/z| &lt; 1. Write the second term as:  
  -1 / (z - 1) = -(1/z) / (1 - 1/z) = - Σ\_(n=0)^∞ z^(-n-1)  
- Here |z| &lt; 2, so |z/2| &lt; 1. Write the first term as:  
  1 / (z - 2) = -(1/2) / (1 - z/2) = - Σ\_(n=0)^∞ (z^n / 2^(n+1))  

Adding both:  
**f(z) = - Σ\_(n=0)^∞ (z^n / 2^(n+1)) - Σ\_(n=0)^∞ z^(-n-1)**

**(ii) Region |z| &gt; 2:**  
Here |2/z| &lt; 1 and |1/z| &lt; 1:  
1 / (z - 2) = (1/z) / (1 - 2/z) = Σ\_(n=0)^∞ 2^n / z^(n+1)  
-1 / (z - 1) = -(1/z) / (1 - 1/z) = - Σ\_(n=0)^∞ 1 / z^(n+1)  
**f(z) = Σ\_(n=0)^∞ (2^n - 1) / z^(n+1)**

**Exam note:** Write the region at the start of each part. Marks are given for the correct series in each region. The partial fraction step alone does not earn full marks.

### 1.14 Residue Calculus (अवशेष कलन)

**Definition:**  
The coefficient b₁ of 1/(z - z₀) in the Laurent expansion of f(z) is the **Residue** (अवशेष) at z = z₀:

> **Res[f(z), z₀] = b₁**

In short, the residue is the strength of the singularity. Only this term survives the loop integral.

**Exam formulas to find the residue:**
1. **Simple pole (order 1):**

> **Res(z₀) = lim\_(z → z₀) (z - z₀) f(z)**  
> If f(z) = P(z)/Q(z), then Res(z₀) = P(z₀) / Q'(z₀).

2. **Pole of order m:**

> **Res(z₀) = [ 1 / (m - 1)! ] · lim\_(z → z₀) (d^(m-1)/dz^(m-1)) [ (z - z₀)^m f(z) ]**

**Cauchy's Residue Theorem:**

> **∮\_C f(z) dz = 2π i · Σ (sum of residues at all poles inside C)**

### 1.15 Value of Real Integrals by Residue Theorem (Contour Integration)

This is a common 15-mark essay question in the exam. There are mainly 3 types.

#### Type 1: Trigonometric Integral ∫₀^(2π) f(cos θ, sin θ) dθ

**Standard substitution:**

> **z = e^(iθ), so dz = i z dθ, dθ = dz / (i z)**  
> **cos θ = (z² + 1) / (2z), sin θ = (z² - 1) / (2i z)**

The integral becomes a complex integral on the unit circle C: |z| = 1. Why it works: the loop integral picks up only the residues of the poles inside the unit circle.

**Solved Numerical 1:**  
**Question:** Prove that ∫₀^(2π) dθ / (5 - 3 cos θ) = π / 2.

**Solution:**  
1. **Substitute:**  
   I = ∮\_(|z|=1) [ dz / (i z) ] / [ 5 - 3(z² + 1)/(2z) ]  
   = ∮\_(|z|=1) [ dz / (i z) ] / [ (10z - 3z² - 3) / (2z) ]  
   = ∮\_(|z|=1) 2 dz / [ i (10z - 3z² - 3) ]  
   = (- 2 / i) ∮\_(|z|=1) dz / (3z² - 10z + 3)  
   = (2 i) ∮\_(|z|=1) dz / [ 3 (z - 1/3)(z - 3) ]

2. **Find the poles inside the circle:**  
   Poles: z = 1/3 and z = 3.  
   Only **z = 1/3** is inside |z| = 1, because |1/3| &lt; 1 and |3| &gt; 1.

3. **Residue at z = 1/3:**  
   Res(1/3) = lim\_(z → 1/3) (z - 1/3) · [ 1 / (3 (z - 1/3)(z - 3)) ]  
   = 1 / [ 3 (1/3 - 3) ] = 1 / [ 3 (-8/3) ] = - 1/8

4. **Residue Theorem:**  
   I = (2 i) · [ 2π i · Res(1/3) ]  
   = (2 i) · [ 2π i · (-1/8) ]  
   = (4π i²) · (-1/8)  
   Since i² = -1: I = (-4π)(-1/8) = 4π / 8 = **π / 2**  
   (Hence proved)

---

#### Type 2: Rational Integrals with Infinite Limits ∫\_(-∞)^(+∞) dx / (x² + 1)²

**Solved Numerical 2:**  
**Question:** Evaluate I = ∫\_(-∞)^(+∞) dx / (x² + 1)² by the residue theorem.

**Solution:**  
1. Write f(z) = 1 / (z² + 1)² = 1 / [ (z + i)² (z - i)² ].  
   The contour C is the real axis from -R to +R, plus the semicircle Γ (|z| = R) in the upper half-plane.
2. Poles: z = +i and z = -i. Both are poles of order 2.  
   Only **z = +i** is in the upper half-plane (Im(z) &gt; 0).
3. Residue at the pole of order 2, z = i:  
   Res(i) = [ 1 / (2 - 1)! ] · lim\_(z → i) d/dz [ (z - i)² / ((z - i)² (z + i)²) ]  
   = lim\_(z → i) d/dz [ (z + i)⁻² ]  
   = lim\_(z → i) [ -2 (z + i)⁻³ ] = -2 / (2i)³  
   = -2 / (-8i) = 1 / (4i) = - i / 4
4. By the residue theorem:  
   I = 2π i · Res(i) = 2π i · [ 1 / (4i) ] = 2π / 4 = **π / 2**  
   **Answer: I = π / 2**

---

#### Type 3: Fourier-type Real Integrals (Jordan's Lemma)

**Solved Numerical 3:**  
**Question:** Prove that ∫\_(-∞)^(+∞) [ cos(mx) / (x² + a²) ] dx = (π / a) · e^(-ma), where m &gt; 0 and a &gt; 0.

**Solution:**  
1. By Euler's formula, e^(imz) = cos(mz) + i sin(mz). We integrate f(z) = e^(imz) / (z² + a²). The real part of the result is the answer.
2. Poles: z² + a² = 0 gives z = +ia and z = -ia. Only **z = +ia** is in the upper half-plane.
3. Residue at the simple pole z = ia:  
   Res(ia) = lim\_(z → ia) (z - ia) · [ e^(imz) / ((z - ia)(z + ia)) ]  
   = e^(im(ia)) / (ia + ia) = e^(-ma) / (2ia)
4. By Jordan's Lemma, the integral over the big semicircle goes to 0 as R → ∞. So:  
   ∮\_C f(z) dz = 2π i · Res(ia) = 2π i · [ e^(-ma) / (2ia) ] = (π / a) · e^(-ma)
5. Compare the real parts:  
   **∫\_(-∞)^(+∞) [ cos(mx) / (x² + a²) ] dx = (π / a) · e^(-ma)**  
   (Hence proved)

---

### 1.15 Detailed 3×3 Solved Numerical on Diagonalization (Complete Diagonalization Problem)

**Question:** Diagonalize A = [ [1, 0, 0], [0, 2, 1], [0, 1, 2] ]. Find the modal matrix P and the diagonal matrix D.

**Solution:**  
**Step 1: Eigenvalues:**  
Characteristic equation: |A - λI| = 0  
(1 - λ)[ (2 - λ)² - 1 ] = 0  
(1 - λ)(λ - 1)(λ - 3) = 0  
So λ₁ = 1, λ₂ = 1, λ₃ = 3. (λ = 1 is repeated.)

**Step 2: Eigenvectors:**  
1. **For λ = 3:**  
   Solve (A - 3I) X = 0:  
   [ [-2, 0, 0], [0, -1, 1], [0, 1, -1] ] X = 0  
   Equation 1: -2x₁ = 0, so x₁ = 0  
   Equation 2: -x₂ + x₃ = 0, so x₂ = x₃  
   Take x₂ = 1, then x₃ = 1.  
   **X₃ = [ [0], [1], [1] ]** (Normalized: [0, 1/√2, 1/√2]ᵀ)

2. **For λ = 1 (repeated root):**  
   Solve (A - I) X = 0:  
   [ [0, 0, 0], [0, 1, 1], [0, 1, 1] ] X = 0  
   Here x₁ is free, and x₂ + x₃ = 0, so x₃ = -x₂.  
   We need two independent eigenvectors:  
   - First choice (x₁ = 1, x₂ = 0, x₃ = 0): **X₁ = [ [1], [0], [0] ]**  
   - Second choice (x₁ = 0, x₂ = 1, x₃ = -1): **X₂ = [ [0], [1], [-1] ]** (Normalized: [0, 1/√2, -1/√2]ᵀ)

**Step 3: Modal matrix P and its inverse:**  
Put the eigenvectors as columns:  
P = [ [1, 0, 0], [0, 1, 1], [0, -1, 1] ]

det(P) = 1(1 - (-1)) = 2 ≠ 0, so P⁻¹ exists:  
P⁻¹ = [ [1, 0, 0], [0, 1/2, -1/2], [0, 1/2, 1/2] ]

**Step 4: Verify D = P⁻¹ A P:**  
A P = [ [1, 0, 0], [0, 1, 3], [0, -1, 3] ]  
D = P⁻¹ (A P) = [ [1, 0, 0], [0, 1, 0], [0, 0, 3] ]

The eigenvalues 1, 1, 3 are on the diagonal. So A is diagonalized.

### 1.16 Poles on the Real Axis: Cauchy Principal Value (कॉची मुख्य मान)

If a pole lies on the real axis (for example at x = 0), the ordinary integral is not defined. We go around the pole with a small semicircle and use the **Cauchy Principal Value (P.V.)**. The small semicircle avoids the pole. Its contribution is a known value, -iπ times the residue.

**Solved Numerical:**  
**Question:** Prove that P.V. ∫\_(-∞)^(+∞) [ (sin x) / x ] dx = π.

**Solution:**  
1. Take f(z) = e^(iz) / z. Its imaginary part is (sin x) / x.
2. z = 0 is a simple pole on the real axis.
3. Draw the contour C: from -R to -ε on the real axis, then a small semicircle C\_ε of radius ε above z = 0, then from ε to +R, then a large semicircle C\_R in the upper half-plane.
4. No pole is inside C. So by Cauchy's theorem:  
   ∮\_C [ e^(iz) / z ] dz = 0
5. On the small semicircle, z = ε e^(iθ), with θ going from π to 0:  
   lim\_(ε→0) ∫\_(C\_ε) [ e^(iz) / z ] dz = - iπ · Res(0) = - iπ
6. By Jordan's lemma, the integral over C\_R goes to 0 as R → ∞.
7. So: P.V. ∫ [ e^(ix) / x ] dx - iπ = 0, which gives  
   P.V. ∫ [ (cos x + i sin x) / x ] dx = iπ
8. Compare the imaginary parts:  
   **P.V. ∫\_(-∞)^(+∞) [ (sin x) / x ] dx = π**  
   Since the function is even, **∫₀^∞ [ (sin x) / x ] dx = π / 2** (Dirichlet integral. Hence proved)

## 1.17 Common Exam Mistakes made by Students (Common Exam Mistakes)

1. **Using poles outside the contour:** Many students add the residue of a pole outside the circle |z| = 1 (such as z = 3 or z = -2). The answer then becomes wrong. First check which poles are inside the contour.
2. **Sign mistake in C-R equations:** The second equation is u\_y = - v\_x. Many students forget the minus sign.
3. **Forgetting the dagger in a Hermitian matrix:** A† means both conjugate (\*) and transpose (T). Taking only the transpose is not enough.
4. **Forgetting 1/(m-1)! for higher-order poles:** For a pole of order 2, the factor is 1/1! = 1. For a pole of order 3, you must multiply by 1/2! = 1/2.

## 2.1 Second Order ODE & Singular Points

### 1. Why do variable-coefficient equations appear in physics?
In B.Sc., you studied equations with **constant coefficients** (like d²y/dx² + ω²y = 0). In real physics, the space is often spherical or cylindrical. When we solve the 3D Laplace equation (∇²V = 0) or the Schrödinger equation in spherical coordinates (r, θ, φ) or cylindrical coordinates (r, θ, z) by **Separation of Variables** (चरों का पृथक्करण), we get **variable coefficients**. These come from terms with r, r², sin θ and cos θ.

**Standard Form:**

> **y'' + P(x) y' + Q(x) y = 0**  
> (Here y'' = d²y/dx² and y' = dy/dx.) This form is the starting point for every problem in this unit.

---

### 2. Ordinary and Singular Points
- **Ordinary Point (साधारण बिंदु):**  
  A point x₀ is an ordinary point if P(x) and Q(x) are both well-behaved at x₀. That means they are analytic and can be written as a Taylor series. There is no infinity here. We find the solution as a power series y = Σ aₙ xⁿ around this point.
- **Singular Point (विचित्र बिंदु):**  
  If P(x) or Q(x) becomes infinite (or undefined) at x₀, then x₀ is a singular point. In physics, this is where a force or potential becomes infinite, for example at the center r = 0.

### 3. Two Types of Singular Points
1. **Regular Singular Point (RSP, नियमित विचित्र बिंदु):**  
   The infinity is mild. The following two limits are both finite:

   &gt; **lim (x → x₀) (x - x₀) · P(x) = finite**  
   &gt; **lim (x → x₀) (x - x₀)² · Q(x) = finite**

   The Frobenius series method works at such points. So classifying the point is the first step of every Frobenius problem.
2. **Irregular Singular Point (ISP, अनियमित विचित्र बिंदु):**  
   If either of the two limits is infinite, the point is an Irregular Singular Point.

**Solved Example (Classifying points, exam question):**  
**Question:** Find the nature of the points x = 0 and x = 1 for the Legendre and Bessel equations.

**Solution:**  
**1. Legendre Equation:** (1 - x²) y'' - 2x y' + n(n + 1) y = 0  
Step 1: Divide by (1 - x²) to get the standard form:  
y'' - [ 2x / (1 - x²) ] y' + [ n(n + 1) / (1 - x²) ] y = 0  
So P(x) = - 2x / (1 - x²) and Q(x) = n(n + 1) / (1 - x²).

- **At x = 0:** P(0) = 0 and Q(0) = n(n+1). Both are finite.  
  So **x = 0 is an Ordinary Point**.
- **At x = 1:** The denominator 1 - 1² = 0. So P(1) and Q(1) are infinite. It is a singular point.  
  Check for RSP:  
  lim (x→1) (x - 1) P(x) = lim (x→1) [ 2x / (1 + x) ] = 2/2 = 1 (finite).  
  lim (x→1) (x - 1)² Q(x) = 0 (finite).  
  So **x = 1 is a Regular Singular Point (RSP)**.

**Why the test works:** A regular singular point is a point where the equation is only mildly singular. The two limits measure how fast P(x) and Q(x) blow up. If they blow up slowly enough, a power series with an extra power r still works. That is the reason we check these limits before starting the Frobenius method.

**2. Bessel Equation:** x² y'' + x y' + (x² - n²) y = 0  
Step 1: Divide by x²:  
y'' + (1/x) y' + [ (x² - n²) / x² ] y = 0  
So P(x) = 1/x and Q(x) = (x² - n²) / x².

- **At x = 0:** P(0) is infinite, so it is a singular point.  
  Check for RSP:  
  lim (x→0) x · P(x) = 1 (finite).  
  lim (x→0) x² · Q(x) = - n² (finite).  
  So **x = 0 is a Regular Singular Point (RSP)**.

## 2.2 Frobenius Method (फ्रोबेनियस विधि)

**In simple words:**  
At a regular singular point x = 0, the ordinary Taylor series y = Σ aₘ xᵐ does not work. The 1/x terms break it. So Frobenius suggested a **generalized series**, with an unknown power r added:

> **Trial series: y = Σ\_(m=0)^∞ aₘ x^(m + r)    (where a₀ ≠ 0)**

**Working Steps (scoring steps):**
1. **Differentiate:**  
   y' = Σ aₘ (m + r) x^(m + r - 1)  
   y'' = Σ aₘ (m + r)(m + r - 1) x^(m + r - 2)
2. Put these in the given equation.
3. **Indicial Equation:** Set the coefficient of the lowest power of x to zero. This gives a quadratic in r. Solve it to get the roots r₁ and r₂. The indicial equation is the starting equation for the power r. It tells you the form of the solutions.
4. **Recurrence Relation:** Set the coefficient of the general power x^(m + r) to zero. This gives aₘ in terms of aₘ₋₁ or aₘ₋₂.

**3 Cases of Roots:**
- **Case 1 (r₁ - r₂ is not an integer):** Two independent solutions: y = c₁ y₁(x) + c₂ y₂(x).
- **Case 2 (r₁ = r₂):** The second solution is found by differentiating with respect to r:  
  y₁ = [y]\_(r = r₁),  y₂ = [∂y/∂r]\_(r = r₁)
- **Case 3 (r₁ - r₂ is an integer):** The second solution has a logarithm (ln x) term.

**Exam note:** In Case 3 the two roots differ by an integer. The power series for the smaller root may then fail to give a second solution. The logarithm term fixes this. You do not need the full derivation in a short question. Just state the case and the form of the second solution.

## 2.3 Legendre Equation & Polynomials (लीजेंड्र समीकरण और बहुपद)

### 1. Physical Meaning
When we solve ∇²V = 0 in spherical polar coordinates (in electrostatics or gravitation), the part with angle θ becomes the **Legendre equation**, with x = cos θ. Its solutions are the Legendre polynomials P\_n(cos θ). They describe multipole potentials, such as dipole and quadrupole.

### 2. Legendre Equation

> **(1 - x²) y'' - 2x y' + n(n + 1) y = 0**

Here n = 0, 1, 2, 3, ... is an integer.

### 3. Rodrigues Formula for P\_n(x)
This formula is the most useful for finding P\_n(x) in exams:

> **P\_n(x) = [ 1 / (2ⁿ · n!) ] · (dⁿ / dxⁿ) [ (x² - 1)ⁿ ]**

**First 5 Legendre polynomials (memorize):**
- **P₀(x) = 1**
- **P₁(x) = x**
- **P₂(x) = (3x² - 1) / 2**
- **P₃(x) = (5x³ - 3x) / 2**
- **P₄(x) = (35x⁴ - 30x² + 3) / 8**

**Special point values:**
- P\_n(1) = 1
- P\_n(-1) = (-1)ⁿ
- For odd n, P\_n(0) = 0
- For even n, P\_n(0) = (-1)^(n/2) · n! / [ 2ⁿ ((n/2)!)² ]

### 4. Generating Function

> **(1 - 2xt + t²)^(-1/2) = Σ\_(n=0)^∞ P\_n(x) · tⁿ    (|t| &lt; 1)**

**Physical idea:** In electrostatics, 1/|r - r'| = 1/√(r² - 2rr' cos θ + r'²). If we put t = r'/r and x = cos θ, this becomes (1 - 2xt + t²)^(-1/2). So the generating function is the basis of the multipole expansion.

### 5. Orthogonality Property

> **∫\_(-1)^(+1) P\_m(x) · P\_n(x) dx = [ 2 / (2n + 1) ] · δ\_mn**

So the integral is 0 for m ≠ n. For m = n, it equals 2 / (2n + 1). This lets us expand any function in Legendre polynomials, as in section 2.9.

### 6. Recurrence Relations of Legendre
1. **(2n + 1) x P\_n(x) = (n + 1) P\_(n+1)(x) + n P\_(n-1)(x)** (most asked)
2. n P\_n(x) = x P'\_n(x) - P'\_(n-1)(x)
3. (2n + 1) P\_n(x) = P'\_(n+1)(x) - P'\_(n-1)(x)
4. (1 - x²) P'\_n(x) = n [ P\_(n-1)(x) - x P\_n(x) ]

**Solved Numerical:**  
**Question:** Find P₂(x) using the Rodrigues formula. Then show that P₂(1) = 1.  
**Solution:**  
Step 1: Put n = 2 in the Rodrigues formula:  
P₂(x) = [ 1 / (2² · 2!) ] d²/dx² (x² - 1)² = (1/8) d²/dx² (x⁴ - 2x² + 1)  
Step 2: First derivative: 4x³ - 4x  
Step 3: Second derivative: 12x² - 4  
Step 4: P₂(x) = (1/8)(12x² - 4) = (3x² - 1) / 2  
Step 5: Put x = 1: P₂(1) = (3 - 1) / 2 = 1. (Verified)

## 2.4 Bessel Equation & Functions (बेसेल समीकरण और फलन)

### 1. Physical Meaning
Bessel functions appear when a problem has **cylindrical symmetry**. Examples are the vibration of a circular drum membrane, electromagnetic waves in a circular pipe or optical fibre, and Fraunhofer diffraction by a circular aperture. In these cases, the radial equation becomes the Bessel equation. So J\_n shows up whenever the problem has a cylinder or a circle.

### 2. Bessel Equation

> **x² y'' + x y' + (x² - n²) y = 0**

Its solution is the **Bessel function of order n**, written J\_n(x).

### 3. Series Form of J\_n(x)

> **J\_n(x) = Σ\_(r=0)^∞ [ (-1)ʳ / (r! · Γ(n + r + 1)) ] · (x / 2)^(n + 2r)**

For integer n: **J\_(-n)(x) = (-1)ⁿ J\_n(x)**

### 4. Generating Function

> **exp[ (x / 2)(t - 1/t) ] = Σ\_(n=-∞)^(+∞) J\_n(x) · tⁿ**

### 5. Half-Integer Order Bessel Functions (Almost every year in exam)

> **J\_(1/2)(x) = √[ 2 / (π x) ] · sin x**  
> **J\_(-1/2)(x) = √[ 2 / (π x) ] · cos x**

**Short Derivation (proof of J\_(1/2)(x)):**  
Step 1: Put n = 1/2 in the series:  
J\_(1/2)(x) = Σ\_(r=0)^∞ [ (-1)ʳ / (r! · Γ(r + 3/2)) ] · (x / 2)^(2r + 1/2)  
= (x / 2)^(1/2) [ 1/Γ(3/2) - (x/2)²/(1! Γ(5/2)) + (x/2)⁴/(2! Γ(7/2)) - ... ]

Step 2: Gamma function values:  
Γ(1/2) = √π  
Γ(3/2) = (1/2) √π  
Γ(5/2) = (3/4) √π  
Γ(7/2) = (15/8) √π

Step 3: Put these values in:  
J\_(1/2)(x) = √(x/2) · [ 1/((1/2)√π) - x²/(4 · (3/4)√π) + x⁴/(32 · (15/8)√π) - ... ]  
J\_(1/2)(x) = √(x/2) · (2/√π) · [ 1 - x²/3! + x⁴/5! - ... ]  
Step 4: Divide by x outside and multiply by x inside the bracket:  
= [ √(x/2) · (2/√π) · (1/x) ] · [ x - x³/3! + x⁵/5! - ... ]  
= √[ 2 / (π x) ] · sin x  
(Hence proved)

### 6. Six Important Recurrence Relations of Bessel
1. **J\_(n-1)(x) + J\_(n+1)(x) = (2n / x) J\_n(x)**
2. **J\_(n-1)(x) - J\_(n+1)(x) = 2 J'\_n(x)**
3. x J'\_n(x) = n J\_n(x) - x J\_(n+1)(x)
4. x J'\_n(x) = - n J\_n(x) + x J\_(n-1)(x)
5. d/dx [ xⁿ J\_n(x) ] = xⁿ J\_(n-1)(x)
6. d/dx [ x^(-n) J\_n(x) ] = - x^(-n) J\_(n+1)(x)

## 2.5 Hermite Differential Equation and Polynomials (हर्माइट बहुपद)

### 1. Physical Significance: Quantum Harmonic Oscillator
In quantum mechanics, a particle in a spring-like potential has V(x) = ½ mω²x². Its Schrödinger equation, written in dimensionless variables, has solutions made of a Hermite polynomial Hₙ(x) times a Gaussian e^(-x²/2).

### 2. Hermite Equation

> **y'' - 2x y' + 2n y = 0**

Here n = 0, 1, 2, ... is a non-negative integer.

### 3. Rodrigues Formula

> **Hₙ(x) = (-1)ⁿ · e^(x²) · (dⁿ / dxⁿ) [ e^(-x²) ]**

**First 5 Hermite polynomials:**
- **H₀(x) = 1**
- **H₁(x) = 2x**
- **H₂(x) = 4x² - 2**
- **H₃(x) = 8x³ - 12x**
- **H₄(x) = 16x⁴ - 48x² + 12**

### 4. Generating Function

> **exp(2xt - t²) = Σ\_(n=0)^∞ [ Hₙ(x) / n! ] · tⁿ**

### 5. Orthogonality (weight function e^(-x²))

> **∫\_(-∞)^(+∞) e^(-x²) · Hₘ(x) · Hₙ(x) dx = √π · 2ⁿ · n! · δₘₙ**

### 6. Quantum State Wavefunction

> **ψₙ(x) = [ (mω / (πħ))^(1/4) / √(2ⁿ n!) ] · Hₙ(αx) · e^(-α²x²/2)**

**Energy eigenvalues:** **Eₙ = (n + 1/2) ħω**  
The zero-point energy E₀ = ½ ħω is consistent with the Heisenberg uncertainty principle. The lowest energy is not zero. This follows directly from the uncertainty principle.

## 2.6 Laguerre Differential Equation and Polynomials (लागुएर बहुपद)

### 1. Physical Significance: Hydrogen Atom
When the Schrödinger equation for the electron in a hydrogen atom, with V(r) = - e² / (4πε₀ r), is solved in spherical coordinates, the radial wavefunction R\_nl(r) is written with **Associated Laguerre Polynomials** L\_(n-l-1)^(2l+1). The Coulomb potential goes as 1/r, which is why Laguerre polynomials appear here.

### 2. Laguerre Equation

> **x y'' + (1 - x) y' + n y = 0**

**Associated Laguerre Equation:**

> **x y'' + (k + 1 - x) y' + n y = 0**

### 3. Rodrigues Formula

> **Lₙ(x) = (eˣ / n!) · (dⁿ / dxⁿ) [ xⁿ · e^(-x) ]**

**First 3 Laguerre polynomials:**
- **L₀(x) = 1**
- **L₁(x) = 1 - x**
- **L₂(x) = 1 - 2x + x²/2**

### 4. Generating Function

> **[ 1 / (1 - t) ] · exp[ - xt / (1 - t) ] = Σ\_(n=0)^∞ Lₙ(x) · tⁿ**

### 5. Orthogonality (weight function e^(-x))

> **∫\_0^∞ e^(-x) · Lₘ(x) · Lₙ(x) dx = δₘₙ**

## 2.7 Derivation of Recurrence Relations (Step-by-Step Exam Derivations)

### Derivation 1: Legendre's First Recurrence Relation (Long Question)
**To prove:** (2n + 1) x Pₙ(x) = (n + 1) Pₙ₊₁(x) + n Pₙ₋₁(x)

**Proof Steps:**  
1. Start with the generating function (Equation 1):  
   (1 - 2xt + t²)^(-1/2) = Σ\_(n=0)^∞ Pₙ(x) tⁿ

2. Differentiate with respect to t:  
   (-1/2)(1 - 2xt + t²)^(-3/2) · (-2x + 2t) = Σ\_(n=0)^∞ n Pₙ(x) t^(n-1)  
   (x - t)(1 - 2xt + t²)^(-3/2) = Σ\_(n=0)^∞ n Pₙ(x) t^(n-1)

3. Multiply both sides by (1 - 2xt + t²):  
   (x - t)(1 - 2xt + t²)^(-1/2) = (1 - 2xt + t²) Σ\_(n=0)^∞ n Pₙ(x) t^(n-1)

4. Put the generating function from Equation 1 on the left:  
   (x - t) Σ Pₙ(x) tⁿ = (1 - 2xt + t²) Σ n Pₙ(x) t^(n-1)

5. Expand both sides:  
   x Σ Pₙ tⁿ - Σ Pₙ t^(n+1) = Σ n Pₙ t^(n-1) - 2x Σ n Pₙ tⁿ + Σ n Pₙ t^(n+1)

6. Compare the coefficients of tⁿ:  
   - Left side: x Pₙ(x) - Pₙ₋₁(x)  
   - Right side: (n + 1) Pₙ₊₁(x) - 2n x Pₙ(x) + (n - 1) Pₙ₋₁(x)

7. Move the terms together:  
   x Pₙ + 2n x Pₙ = (n + 1) Pₙ₊₁ + n Pₙ₋₁  
   **(2n + 1) x Pₙ(x) = (n + 1) Pₙ₊₁(x) + n Pₙ₋₁(x)**  
   (Hence proved)

---

### Derivation 2: Bessel's First Recurrence Relation
**To prove:** J\_(n-1)(x) + J\_(n+1)(x) = (2n / x) J\_n(x)

**Proof Steps:**  
1. Start with the generating function (Equation 1):  
   exp[(x/2)(t - 1/t)] = Σ\_(n=-∞)^(+∞) J\_n(x) tⁿ

2. Differentiate with respect to t:  
   exp[(x/2)(t - 1/t)] · (x/2)(1 + 1/t²) = Σ\_(n=-∞)^(+∞) n J\_n(x) t^(n-1)

3. Use Equation 1 on the left:  
   (x/2)(1 + 1/t²) Σ J\_n(x) tⁿ = Σ n J\_n(x) t^(n-1)  
   (x/2) [ Σ J\_n(x) tⁿ + Σ J\_n(x) t^(n-2) ] = Σ n J\_n(x) t^(n-1)

4. Compare the coefficients of t^(n-1):  
   (x/2) [ J\_(n-1)(x) + J\_(n+1)(x) ] = n J\_n(x)

5. Multiply both sides by 2/x:  
   **J\_(n-1)(x) + J\_(n+1)(x) = (2n / x) J\_n(x)**  
   (Hence proved)

## 2.8 Complete Solved Numerical of Frobenius Method (Complete Solved Frobenius Problem)

**Question:** Find the series solution of 4x y'' + 2 y' + y = 0 about x = 0 by the Frobenius method.

**Solution Steps:**  
**Step 1: Check the singular point.**  
Standard form: y'' + [1 / (2x)] y' + [1 / (4x)] y = 0.  
So P(x) = 1/(2x) and Q(x) = 1/(4x). Both are infinite at x = 0.  
Check: lim (x→0) x P(x) = 1/2 (finite). lim (x→0) x² Q(x) = 0 (finite).  
So **x = 0 is a Regular Singular Point (RSP)**.

**Step 2: Assume the Frobenius series:**  
y = Σ aₘ x^(m + r)    (a₀ ≠ 0)  
y' = Σ aₘ (m + r) x^(m + r - 1)  
y'' = Σ aₘ (m + r)(m + r - 1) x^(m + r - 2)

**Step 3: Substitute into 4x y'' + 2 y' + y = 0:**  
Σ aₘ [ 4(m + r)(m + r - 1) + 2(m + r) ] x^(m + r - 1) + Σ aₘ x^(m + r) = 0  
Simplify the first bracket: 2(m + r)(2m + 2r - 1).  
So: Σ aₘ 2(m + r)(2m + 2r - 1) x^(m + r - 1) + Σ aₘ x^(m + r) = 0

**Step 4: Indicial equation** (coefficient of x^(r-1), with m = 0):  
2r(2r - 1) a₀ = 0. Since a₀ ≠ 0:  
2r(2r - 1) = 0, so **r₁ = 1/2, r₂ = 0**  
Here r₁ - r₂ = 1/2, which is not an integer (Case 1). So we get two independent solutions.

**Why this matters:** Because the roots differ by 1/2, each root gives its own power series. The two series are independent. The general solution is their sum, with two arbitrary constants c₁ and c₂.

**Step 5: Recurrence relation:**  
2(m + r + 1)(2m + 2r + 1) a\_(m+1) + aₘ = 0  
**a\_(m+1) = - aₘ / [ 2(m + r + 1)(2m + 2r + 1) ]**

**Step 6: First solution (r₁ = 1/2):**  
a\_(m+1) = - aₘ / [ (2m + 3)(2m + 2) ]
- m = 0: a₁ = - a₀ / (3 · 2) = - a₀ / 3!
- m = 1: a₂ = - a₁ / (5 · 4) = + a₀ / 5!
- m = 2: a₃ = - a₂ / (7 · 6) = - a₀ / 7!  
So y₁ = x^(1/2) a₀ [ 1 - x/3! + x²/5! - x³/7! + ... ]  
Multiply and divide by √x:  
**y₁ = a₀ sin(√x)**

**Step 7: Second solution (r₂ = 0):**  
a\_(m+1) = - aₘ / [ (2m + 2)(2m + 1) ]
- m = 0: a₁ = - a₀ / 2!
- m = 1: a₂ = + a₀ / 4!
- m = 2: a₃ = - a₀ / 6!  
So **y₂ = a₀ cos(√x)**

**Complete solution:**  
> **y(x) = c₁ sin(√x) + c₂ cos(√x)**

Check by substitution: both parts satisfy 4x y'' + 2 y' + y = 0.

## 2.9 Expansion of Functions in terms of Legendre Polynomials

**In simple words:** Just as a vector is split into components along î, ĵ and k̂, a polynomial can be split into components along P₀, P₁, P₂, P₃, and so on. Method: write each power xⁿ in terms of Legendre polynomials, then add the pieces.

**Solved Numerical:**  
**Question:** Write f(x) = 7x³ - 3x² + 2x + 5 in terms of Legendre polynomials.

**Solution:**  
Step 1: Write x³ and x² in terms of Legendre polynomials:  
- P₃(x) = (5x³ - 3x) / 2, so x³ = (2/5) P₃(x) + (3/5) x  
- P₂(x) = (3x² - 1) / 2, so x² = (2/3) P₂(x) + 1/3  
- x = P₁(x), and 1 = P₀(x)

Step 2: Put these in f(x):  
f(x) = 7 [ (2/5) P₃ + (3/5) x ] - 3 [ (2/3) P₂ + 1/3 ] + 2x + 5  
= (14/5) P₃ + (21/5) x - 2 P₂ - 1 + 2x + 5

Step 3: Collect the x-terms and the constant terms. The x-terms give 21/5 + 2, and the constants give 5 - 1:  
= (14/5) P₃ - 2 P₂ + (31/5) x + 4

Step 4: Write x = P₁ and 1 = P₀:  
**f(x) = (14/5) P₃(x) - 2 P₂(x) + (31/5) P₁(x) + 4 P₀(x)**

## 2.10 Higher Half-Integer Bessel Functions: J\_(3/2)(x) and J\_(-3/2)(x)

**Solved Numerical:**  
**Question:** Using the Bessel recurrence relation, prove that:  
J\_(3/2)(x) = √[ 2 / (π x) ] · [ (sin x)/x - cos x ]  
and  
J\_(-3/2)(x) = - √[ 2 / (π x) ] · [ (cos x)/x + sin x ]

**Solution:**  
Step 1: Write the recurrence relation:  
J\_(n-1)(x) + J\_(n+1)(x) = (2n / x) J\_n(x)  
so J\_(n+1)(x) = (2n / x) J\_n(x) - J\_(n-1)(x)

Step 2: For J\_(3/2), put n = 1/2:  
J\_(3/2)(x) = (1/x) J\_(1/2)(x) - J\_(-1/2)(x)  
Substitute J\_(1/2) = √[2/(πx)] sin x and J\_(-1/2) = √[2/(πx)] cos x:  
**J\_(3/2)(x) = √[ 2 / (π x) ] · [ (sin x)/x - cos x ]** (Hence proved)

Step 3: For J\_(-3/2), put n = -1/2 in J\_(n-1) = (2n/x) J\_n - J\_(n+1):  
J\_(-3/2)(x) = - (1/x) J\_(-1/2)(x) - J\_(1/2)(x)  
= - (1/x) √[2/(πx)] cos x - √[2/(πx)] sin x  
**J\_(-3/2)(x) = - √[ 2 / (π x) ] · [ (cos x)/x + sin x ]** (Hence proved)

**Pattern to remember:** Each half-integer Bessel function is a sine or cosine divided by √x, with extra terms in 1/x. Once J\_(1/2) and J\_(-1/2) are known, the recurrence relation gives all the others. So learn those two first.

## 2.11 Evaluation of Integrals of Hermite Polynomials

**Solved Numerical:**  
**Question:** Prove that ∫\_(-∞)^(+∞) x · e^(-x²) · Hₙ(x) · Hₙ₋₁(x) dx = √π · 2ⁿ⁻¹ · n!

**Solution:**  
Step 1: Hermite's recurrence relation is 2x Hₙ(x) = Hₙ₊₁(x) + 2n Hₙ₋₁(x). So:  
x Hₙ(x) = (1/2) Hₙ₊₁(x) + n Hₙ₋₁(x)

Step 2: Put this in the integral:  
I = ∫ e^(-x²) [x Hₙ(x)] Hₙ₋₁(x) dx  
= (1/2) ∫ e^(-x²) Hₙ₊₁(x) Hₙ₋₁(x) dx + n ∫ e^(-x²) [Hₙ₋₁(x)]² dx

Step 3: Use orthogonality:  
- First integral: the indices n + 1 and n - 1 are different, so it is 0.  
- Second integral: ∫ e^(-x²) [Hₘ(x)]² dx = √π 2ᵐ m!. With m = n - 1, this is √π 2ⁿ⁻¹ (n - 1)!.

Step 4: Therefore:  
I = 0 + n · √π 2ⁿ⁻¹ (n - 1)!  
**I = √π · 2ⁿ⁻¹ · n!** (Hence proved)

## 2.13 Complete Derivation of Legendre Orthogonality Value

**To prove:** ∫\_(-1)^(+1) [Pₙ(x)]² dx = 2 / (2n + 1)

**Proof Steps:**  
1. Start with the generating function:  
   (1 - 2xt + t²)^(-1/2) = Σ\_(n=0)^∞ Pₙ(x) tⁿ   (Equation 1)

2. Square both sides:  
   (1 - 2xt + t²)⁻¹ = Σ\_(n=0)^∞ Σ\_(m=0)^∞ Pₙ(x) Pₘ(x) t^(n+m)

3. Integrate from -1 to +1 with respect to x:  
   ∫\_(-1)^(+1) (1 - 2xt + t²)⁻¹ dx = Σₙ Σₘ tⁿ⁺ᵐ ∫\_(-1)^(+1) Pₙ(x) Pₘ(x) dx

4. For m ≠ n, the integral is 0 by orthogonality. Only m = n terms remain:  
   Right side = Σ\_(n=0)^∞ t^(2n) ∫\_(-1)^(+1) [Pₙ(x)]² dx

5. Solve the integral on the left. Let u = 1 - 2xt + t². Then du = -2t dx, so dx = -du / (2t).  
   At x = -1: u = (1 + t)². At x = +1: u = (1 - t)².  
   Left side = (1 / 2t) [ ln u ] from (1 - t)² to (1 + t)²  
   = (1 / 2t) [ ln(1 + t)² - ln(1 - t)² ]  
   = (1 / t) [ ln(1 + t) - ln(1 - t) ]

6. Use the log series:  
   ln(1 + t) = t - t²/2 + t³/3 - t⁴/4 + ...  
   ln(1 - t) = - t - t²/2 - t³/3 - t⁴/4 - ...  
   So ln(1 + t) - ln(1 - t) = 2 [ t + t³/3 + t⁵/5 + ... + t^(2n+1)/(2n + 1) + ... ]  
   Left side = 2 [ 1 + t²/3 + t⁴/5 + ... + t^(2n)/(2n + 1) + ... ] = Σ\_(n=0)^∞ [ 2 / (2n + 1) ] t^(2n)

7. Compare the coefficients of t^(2n) on both sides:  
   **∫\_(-1)^(+1) [Pₙ(x)]² dx = 2 / (2n + 1)**  
   (Hence proved. A 10-mark compulsory question.)

## 2.14 Origin of Hermite Equation in Quantum Physics

**Question:** Derive the Hermite equation from the time-independent Schrödinger equation of a 1D simple harmonic oscillator. Then derive Eₙ = (n + 1/2) ħω.

**Solution Steps:**  
1. Schrödinger equation:  
   - (ħ² / 2m) d²ψ/dx² + (1/2) mω² x² ψ = E ψ  
   So d²ψ/dx² + (2m/ħ²) [ E - (1/2) mω² x² ] ψ = 0

2. Dimensionless variable: let α = (mω / ħ)^(1/2) and y = αx. Then d²ψ/dx² = α² d²ψ/dy². Substitute:  
   d²ψ/dy² + [ (2E / ħω) - y² ] ψ = 0  
   Let λ = 2E / (ħω). Then:  
   **d²ψ/dy² + (λ - y²) ψ = 0**   (Equation 1)

3. Asymptotic behaviour (y → ∞): For very large y, λ is small compared with y². So d²ψ/dy² - y² ψ ≈ 0. Its finite solution is ψ(y) ~ e^(-y²/2).

4. Assume the full solution:  
   ψ(y) = e^(-y²/2) · H(y)   (Equation 2)

5. Differentiate and substitute into Equation 1:  
   dψ/dy = - y e^(-y²/2) H + e^(-y²/2) H'  
   d²ψ/dy² = (y² - 1) e^(-y²/2) H - 2y e^(-y²/2) H' + e^(-y²/2) H''  
   After cancelling e^(-y²/2):  
   **H'' - 2y H' + (λ - 1) H = 0**   (Equation 3)

6. Compare with the Hermite equation H'' - 2y H' + 2n H = 0:  
   λ - 1 = 2n, so λ = 2n + 1.  
   Since λ = 2E / (ħω): 2E / (ħω) = 2n + 1  
   **Eₙ = (n + 1/2) ħω**, where n = 0, 1, 2, ...  
   (Hence proved. The most important derivation in quantum mechanics.)

**Physical result:** The energy levels are equally spaced, with gap ħω. The ground state has E₀ = ½ ħω. So the oscillator never sits exactly at rest, even at zero temperature. This follows from the uncertainty principle.

## 2.15 Complete Derivation of Bessel's Second Recurrence Relation

**To prove:** J\_(n-1)(x) - J\_(n+1)(x) = 2 J'\_n(x)

**Proof Steps:**  
1. Start with the generating function:  
   exp[(x/2)(t - 1/t)] = Σ\_(n=-∞)^(+∞) J\_n(x) tⁿ   (Equation 1)

2. Differentiate with respect to x:  
   exp[(x/2)(t - 1/t)] · (1/2)(t - 1/t) = Σ\_(n=-∞)^(+∞) J'\_n(x) tⁿ

3. Use Equation 1 on the left:  
   (1/2)(t - 1/t) Σ J\_n(x) tⁿ = Σ J'\_n(x) tⁿ  
   (1/2) [ Σ J\_n(x) t^(n+1) - Σ J\_n(x) t^(n-1) ] = Σ J'\_n(x) tⁿ

4. Compare the coefficients of tⁿ:  
   - In the first sum, tⁿ comes from n → n - 1, giving J\_(n-1)(x).  
   - In the second sum, tⁿ comes from n → n + 1, giving - J\_(n+1)(x).  
   - The right side gives J'\_n(x).  
   So (1/2) [ J\_(n-1)(x) - J\_(n+1)(x) ] = J'\_n(x)

5. Multiply both sides by 2:  
   **J\_(n-1)(x) - J\_(n+1)(x) = 2 J'\_n(x)**  
   (Hence proved)

## 2.16 Associated Laguerre Polynomials in Hydrogen Atom

**Physical concept:**  
The radial equation of the hydrogen atom is:  
(1/r²) d/dr [ r² dR/dr ] + [ (2m/ħ²)(E + e²/(4πε₀ r)) - l(l + 1)/r² ] R = 0

Put the dimensionless radius ρ = 2r / (n a₀). For bound states (E &lt; 0), the solution is:  
> **R\_nl(r) = - [ (2/(n a₀))³ · (n - l - 1)! / (2n (n + l)!) ]^(1/2) · e^(-ρ/2) · ρˡ · L\_(n-l-1)^(2l+1)(ρ)**

**Atomic Orbitals:**
1. **1s orbital (n = 1, l = 0):**  
   ρ = 2r / a₀. The Laguerre part is L₀¹(ρ) = 1, because n - l - 1 = 0.  
   **R₁₀(r) = 2 (a₀)^(-3/2) · e^(-r/a₀)**  
   The radial probability is largest at the nucleus and falls to zero as r → ∞.

2. **2p orbital (n = 2, l = 1):**  
   ρ = 2r / (2a₀) = r / a₀. The Laguerre part is L₀³(ρ) = 1, because n - l - 1 = 0. (The polynomial L₃³(ρ) = 20 - 15ρ + 3ρ² - ρ³/6 has the same superscript, but its index is n + l, which is not used here.)  
   **R₂₁(r) = (1 / (2√6)) (a₀)^(-3/2) · (r / a₀) · e^(-r / (2a₀))**  
   There is a node at the nucleus (r = 0), because of the centrifugal barrier for l = 1.

## 2.17 Common Mistakes in Special Functions

1. **Wrong limits of orthogonality:**
   - Legendre: -1 to +1 (weight function 1).
   - Bessel: 0 to a (weight function x).
   - Hermite: -∞ to +∞ (weight function e^(-x²)).
   - Laguerre: 0 to ∞ (weight function e^(-x)).  
   Wrong limits can cost all the marks for a derivation.
2. **Sign in the Rodrigues formula:** In Hermite, (-1)ⁿ is outside. In Legendre and Laguerre, there is no (-1)ⁿ outside.
3. **Sine and cosine in half-integer Bessel:** J\_(1/2)(x) has sin x and J\_(-1/2)(x) has cos x. Memory tip: "Positive half is Sine."

## Part A: Laplace Transform (लाप्लास ट्रांसफॉर्म)

### 3.1 What is Laplace Transform and why is it useful in physics?

**In simple words:**  
In physics and electronics, many equations change with time t. Examples are a spring-mass system, or the current in an RLC circuit. These differential equations are hard to solve directly.

The **Laplace Transform** is a tool. It changes a differential equation in the time domain (t) into an **algebraic equation** in the frequency domain (s).
- Differentiation (d/dt) becomes multiplication by s.
- We find Y(s) using simple algebra.
- Then we use the **Inverse Laplace Transform (L⁻¹)** to get back y(t).

**Definition:**  
Let f(t) be a function for t ≥ 0. Its Laplace Transform F(s) is:

> **L{f(t)} = F(s) = ∫₀^∞ e^(-st) · f(t) dt**

Here s is a parameter. It can be real or complex. Think of F(s) as a picture of f(t) in the frequency domain.

**Existence conditions:** The Laplace Transform exists only when:
1. **Piecewise continuous:** f(t) is continuous in every finite interval. It can have jumps, but only a finite number of them.
2. **Exponential order γ:** f(t) does not grow faster than an exponential. That is, |f(t)| ≤ M e^(γt) for large t. Example: e^(t²) grows too fast, so its Laplace transform does not exist.

### 3.2 Master Table of Laplace Transforms of Standard Functions

| S.No. | Original Function f(t) | Laplace Transform L{f(t)} = F(s) | Region of Convergence (ROC) |
| :--- | :--- | :--- | :--- |
| 1 | **1** (Unit constant) | **1 / s** | s &gt; 0 |
| 2 | **tⁿ** (n positive integer) | **n! / s^(n+1)** | s &gt; 0 |
| 3 | **t^p** (p &gt; -1, real) | **Γ(p + 1) / s^(p+1)** | s &gt; 0 |
| 4 | **t^(1/2)** | **√π / (2 s^(3/2))** | s &gt; 0 |
| 5 | **e^(at)** | **1 / (s - a)** | s &gt; a |
| 6 | **sin(at)** | **a / (s² + a²)** | s &gt; 0 |
| 7 | **cos(at)** | **s / (s² + a²)** | s &gt; 0 |
| 8 | **sinh(at)** | **a / (s² - a²)** | s &gt; \|a\| |
| 9 | **cosh(at)** | **s / (s² - a²)** | s &gt; \|a\| |

**Why this table matters:** Most Laplace problems in exams reduce to these standard forms. If you know the table well, you can match an answer quickly. Only the shifting and derivative rules are then needed on top of it.

**Short derivation (sin and cos):**  
Step 1: By Euler's formula, e^(iat) = cos(at) + i sin(at). Take the Laplace Transform of both sides:  
L{cos at} + i L{sin at} = L{e^(iat)} = 1 / (s - ia)

Step 2: Rationalize the denominator:  
1 / (s - ia) = (s + ia) / (s² + a²) = [ s / (s² + a²) ] + i [ a / (s² + a²) ]

Step 3: Compare the real and imaginary parts:  
**L{cos at} = s / (s² + a²)**  
**L{sin at} = a / (s² + a²)**  
(Hence proved)

### 3.3 Shifting Theorems (शिफ्टिंग प्रमेय)

#### 1. First Shifting Theorem (Frequency Shift)
**Statement:** If L{f(t)} = F(s), then for any constant a:

> **L{ e^(at) · f(t) } = F(s - a)**

**In simple words:** If f(t) is multiplied by e^(at), then replace s by (s - a) in F(s). This is like frequency shift in radio.

**Solved Example 1:**  
**Question:** Find L{ e^(3t) · cos(2t) }.  
**Solution:**  
Step 1: L{cos 2t} = s / (s² + 4) = F(s).  
Step 2: Replace s by (s - 3):  
L{ e^(3t) cos 2t } = F(s - 3) = (s - 3) / [ (s - 3)² + 4 ]  
= (s - 3) / (s² - 6s + 13)

#### 2. Second Shifting Theorem (Time Delay)
**Statement:** The Heaviside unit step function u(t - a) is 0 for t &lt; a and 1 for t ≥ a. It is like a switch turned on at time t = a.  
If L{f(t)} = F(s), then with a time delay a:

> **L{ f(t - a) · u(t - a) } = e^(-as) · F(s)**

**Solved Example 2:**  
**Question:** Find L{ (t - 2)² · u(t - 2) }.  
**Solution:**  
Step 1: Here a = 2 and f(t) = t².  
Step 2: L{t²} = 2! / s³ = 2 / s³ = F(s).  
Step 3: By the second shifting theorem:  
L{ (t - 2)² u(t - 2) } = e^(-2s) · F(s) = **2 e^(-2s) / s³**

### 3.4 Laplace Transform of Derivatives and Integrals

#### 1. Transforms of Derivatives
This formula turns a differential equation into an algebraic equation:

> **L{ f'(t) } = s · F(s) - f(0)**  
> **L{ f''(t) } = s² · F(s) - s · f(0) - f'(0)**  
> **L{ f'''(t) } = s³ · F(s) - s² · f(0) - s · f'(0) - f''(0)**

Here f(0) and f'(0) are **initial conditions**. In physics, they are the initial position and initial velocity.

#### 2. Laplace Transform of Integrals

> **L{ ∫₀^t f(u) du } = F(s) / s**

#### 3. Multiplication by tⁿ

> **L{ tⁿ · f(t) } = (-1)ⁿ · (dⁿ / dsⁿ) F(s)**

For n = 1: **L{ t f(t) } = - d/ds [F(s)]**

**Solved Example 3:**  
**Question:** Find L{ t · sin(at) }.  
**Solution:**  
Step 1: L{sin at} = a / (s² + a²) = F(s).  
Step 2: Use the rule:  
L{ t sin at } = - d/ds [ a / (s² + a²) ]  
= - a · [ - 2s / (s² + a²)² ]  
= **2as / (s² + a²)²**

#### 4. Division by t

> **L{ f(t) / t } = ∫\_s^∞ F(u) du**  
> (This works if lim (t→0) [f(t)/t] is finite.)

### 3.5 Inverse Laplace Transform and Convolution Theorem

**Definition:** If L{f(t)} = F(s), then f(t) is the Inverse Laplace Transform:

> **f(t) = L⁻¹{F(s)}**

#### 1. Partial Fractions Method

**Solved Numerical 1 (Exam standard):**  
**Question:** Find L⁻¹ [ (5s + 3) / ((s - 1)(s + 2)(s + 3)) ].

**Solution:**  
Step 1: Write in partial fractions:  
(5s + 3) / [ (s - 1)(s + 2)(s + 3) ] = A / (s - 1) + B / (s + 2) + C / (s + 3)

Step 2: Find A, B and C:
- At s = 1: A = (5 + 3) / [ (3)(4) ] = 8 / 12 = 2/3
- At s = -2: B = (-10 + 3) / [ (-3)(1) ] = 7/3
- At s = -3: C = (-15 + 3) / [ (-4)(-1) ] = -3

Step 3: Use L⁻¹{1 / (s - a)} = e^(at):  
**f(t) = (2/3) e^t + (7/3) e^(-2t) - 3 e^(-3t)**

#### 2. Convolution Theorem (कनवोल्यूशन प्रमेय)

**Statement:** If L⁻¹{F(s)} = f(t) and L⁻¹{G(s)} = g(t), then the inverse of the product F(s) G(s) is the convolution:

> **L⁻¹{ F(s) · G(s) } = ∫₀^t f(u) · g(t - u) du = (f \* g)(t)**

Use: the convolution turns a product in the s-domain into an integral in the t-domain.

**Solved Numerical 2:**  
**Question:** Find L⁻¹ [ 1 / (s² (s + 1)) ] using the Convolution Theorem.

**Solution:**  
Step 1: Let F(s) = 1/s², so f(t) = t. Let G(s) = 1/(s + 1), so g(t) = e^(-t).

Step 2: By the Convolution Theorem:  
L⁻¹ [ 1 / (s²(s + 1)) ] = ∫₀^t u · e^(-(t - u)) du = e^(-t) ∫₀^t u · e^u du

Step 3: Integration by parts: ∫ u e^u du = u e^u - e^u  
= e^(-t) [ (u e^u - e^u) ] from 0 to t  
= e^(-t) [ (t e^t - e^t) - (0 - 1) ]  
= e^(-t) [ t e^t - e^t + 1 ]  
= **t - 1 + e^(-t)**

### 3.6 Solving ODEs with Laplace Transform

This is one of the most scoring long questions in the M.Sc. exam.

**Solved Numerical 1 (Simple Harmonic Oscillator):**  
**Question:** Solve y'' + 4y = 0, with y(0) = 2 and y'(0) = 0.

**Solution:**  
Step 1: Take the Laplace Transform of both sides:  
[ s² Y(s) - s y(0) - y'(0) ] + 4 Y(s) = 0

Step 2: Put y(0) = 2 and y'(0) = 0:  
[ s² Y(s) - 2s ] + 4 Y(s) = 0  
(s² + 4) Y(s) = 2s  
Y(s) = 2s / (s² + 4) = 2 · [ s / (s² + 2²) ]

Step 3: Take the inverse transform:  
**y(t) = 2 cos(2t)**

---

**Solved Numerical 2 (Damped Harmonic Oscillator):**  
**Question:** Solve y'' + 2y' + 5y = 0, with y(0) = 1 and y'(0) = -1.

**Solution:**  
Step 1: Take the Laplace Transform:  
[ s² Y(s) - s y(0) - y'(0) ] + 2 [ s Y(s) - y(0) ] + 5 Y(s) = 0

Step 2: Put in the values:  
[ s² Y(s) - s + 1 ] + 2 [ s Y(s) - 1 ] + 5 Y(s) = 0  
(s² + 2s + 5) Y(s) - s - 1 = 0  
(s² + 2s + 5) Y(s) = s + 1  
Y(s) = (s + 1) / (s² + 2s + 5)

Step 3: Complete the square in the denominator:  
s² + 2s + 5 = (s + 1)² + 2²  
So Y(s) = (s + 1) / [ (s + 1)² + 2² ]

Step 4: By the first shifting theorem, (s + 1) means multiplying by e^(-t):  
**y(t) = e^(-t) · cos(2t)**

**Check:** Put t = 0 in the answer and you get y(0) = 1, as required. Differentiate once and put t = 0. You get y'(0) = -1, as required. So the answer satisfies both initial conditions.

## Part B: Fourier Transform and Fourier Series (फूरियर ट्रांसफॉर्म और फूरियर श्रेणी)

### 3.7 Fourier Sine and Cosine Transforms

**In simple words:**  
The Laplace Transform is used for problems where t ≥ 0. The Fourier Transform is used for waves in space and for heat conduction. For a range from 0 to ∞, we use the Fourier Sine and Cosine Transforms.

#### 1. Fourier Sine Transform

> **F\_s{f(x)} = F\_s(s) = ∫₀^∞ f(x) · sin(sx) dx**  
> **Inverse: f(x) = (2/π) ∫₀^∞ F\_s(s) · sin(sx) ds**

#### 2. Fourier Cosine Transform

> **F\_c{f(x)} = F\_c(s) = ∫₀^∞ f(x) · cos(sx) dx**  
> **Inverse: f(x) = (2/π) ∫₀^∞ F\_c(s) · cos(sx) ds**

**Solved Numerical:**  
**Question:** Find the Fourier Sine and Cosine Transforms of f(x) = e^(-ax), where a &gt; 0.  
**Solution:**  
From standard integrals:  
∫₀^∞ e^(-ax) sin(sx) dx = s / (s² + a²)  
∫₀^∞ e^(-ax) cos(sx) dx = a / (s² + a²)  
So:  
**F\_s{e^(-ax)} = s / (s² + a²)**  
**F\_c{e^(-ax)} = a / (s² + a²)**

### 3.8 Dirac Delta Function (डिराक डेल्टा फलन)

**In simple words:**  
Think of a hammer hit. It acts for a very short time, but the force is very large. The total effect is a finite impulse. To describe such an instant effect, Paul Dirac introduced the **Dirac Delta Function δ(x - a)**.

**Definition:**

> **δ(x - a) = 0  (when x ≠ a)**  
> **∫\_(-∞)^(+∞) δ(x - a) dx = 1**

**Sifting Property (most important):**  
When δ is multiplied by a continuous function f(x) and integrated, it picks out only the value at x = a:

> **∫\_(-∞)^(+∞) f(x) · δ(x - a) dx = f(a)**

Think of δ as a sampling point. It reads the value of f at exactly one place.

**Other important properties (2-mark questions):**
1. **Even:** δ(-x) = δ(x)
2. **Scaling:** δ(cx) = (1 / |c|) · δ(x)
3. x · δ(x) = 0
4. **Derivative sifting:** ∫ f(x) · δ'(x - a) dx = - f'(a)
5. **Fourier Transform of δ:**  
   F{δ(x - x₀)} = [1 / √(2π)] ∫ δ(x - x₀) e^(isx) dx = **[1 / √(2π)] · e^(isx₀)**  
   For x₀ = 0: F{δ(x)} = 1 / √(2π). This is a uniform spectrum at all frequencies, like white noise.

### 3.9 Fourier Series & Euler's Formulas (फूरियर श्रेणी)

**In simple words:**  
Joseph Fourier showed that any periodic wave, such as a guitar note, a square pulse or an ECG heartbeat, can be written as a sum of pure sine and cosine waves. These are the fundamental frequency and its harmonics.

**Dirichlet's conditions for convergence:** The Fourier series of f(x) in [-L, L] exists if:
1. f(x) is single-valued and bounded.
2. f(x) has only a finite number of finite discontinuities in the interval.
3. f(x) has a finite number of maxima and minima. These are sufficient conditions. Almost all waves used in physics satisfy them.

**Form of the Fourier series (interval [-π, π]):**

> **f(x) = a₀ / 2 + Σ\_(n=1)^∞ [ aₙ cos(nx) + bₙ sin(nx) ]**

**Euler's formulas:**

> **a₀ = (1/π) ∫\_(-π)^(+π) f(x) dx**  
> **aₙ = (1/π) ∫\_(-π)^(+π) f(x) cos(nx) dx**  
> **bₙ = (1/π) ∫\_(-π)^(+π) f(x) sin(nx) dx**

**Shortcuts for even and odd functions:**
- **Even function, f(-x) = f(x):** sine is odd, so **bₙ = 0**. Only cosine terms remain.  
  a₀ = (2/π) ∫₀^π f(x) dx  
  aₙ = (2/π) ∫₀^π f(x) cos(nx) dx
- **Odd function, f(-x) = -f(x):** cosine is even, so **a₀ = 0 and aₙ = 0**. Only sine terms remain.  
  bₙ = (2/π) ∫₀^π f(x) sin(nx) dx

### 3.10 Fourier Expansion of Square and Triangular Waves

These two derivations are often asked as 15-mark essay questions in the MGSU exam.

#### 1. Square Wave: Complete Exam Solution
**Question:** Find the Fourier series of the square wave in (-π, π):  
f(x) = -k  for -π &lt; x &lt; 0  
f(x) = +k  for 0 &lt; x &lt; π  
Then prove that π / 4 = 1 - 1/3 + 1/5 - 1/7 + ...

**Solution:**  
Step 1: Symmetry: f(-x) = -f(x), so f is an **odd function**. So a₀ = 0 and aₙ = 0. We only need bₙ.

Step 2: Find bₙ:  
bₙ = (2/π) ∫₀^π k sin(nx) dx = (2k / π) [ -cos(nx) / n ] from 0 to π  
= (2k / (nπ)) [ 1 - cos(nπ) ]  
Since cos(nπ) = (-1)ⁿ:  
bₙ = (2k / (nπ)) [ 1 - (-1)ⁿ ]
- If n is even (2, 4, 6, ...): 1 - 1 = 0, so **bₙ = 0**.
- If n is odd (1, 3, 5, ...): 1 - (-1) = 2, so **bₙ = 4k / (nπ)**.

Step 3: Write the series:  
**f(x) = (4k / π) [ sin x + (1/3) sin 3x + (1/5) sin 5x + (1/7) sin 7x + ... ]**

Step 4: Deduce the series. Put x = π/2, where f is continuous and equal to k. Using sin(π/2) = 1, sin(3π/2) = -1, sin(5π/2) = 1, ...:  
k = (4k / π) [ 1 - 1/3 + 1/5 - 1/7 + ... ]  
Cancel k:  
**π / 4 = 1 - 1/3 + 1/5 - 1/7 + ...**  
(Hence proved. This is the Gregory-Leibniz series.)

**Note on the jump:** The square wave jumps at x = 0. There the series gives the average of the two limits, which is 0. At x = π/2 the function is continuous and equal to k. So the series equals k exactly there, and that is why this point is used.

---

#### 2. Triangular Wave: Complete Exam Solution
**Question:** Find the Fourier series of f(x) = |x| in (-π, π). Then prove that 1 + 1/3² + 1/5² + ... = π² / 8.

**Solution:**  
Step 1: Symmetry: f(-x) = |-x| = |x| = f(x). So f is an **even function**. Therefore **bₙ = 0**.

Step 2: Find a₀:  
a₀ = (2/π) ∫₀^π x dx = (2/π) [ x²/2 ] from 0 to π = (2/π)(π²/2) = **π**  
So the first term a₀/2 = **π/2**.

Step 3: Find aₙ:  
aₙ = (2/π) ∫₀^π x cos(nx) dx  
Integration by parts:  
aₙ = (2/π) [ x sin(nx) / n + cos(nx) / n² ] from 0 to π  
Since sin(nπ) = 0 and sin 0 = 0:  
= (2/π) [ (cos(nπ) - cos 0) / n² ]  
= (2 / (πn²)) [ (-1)ⁿ - 1 ]
- If n is even: (-1)ⁿ - 1 = 0, so **aₙ = 0**.
- If n is odd: (-1)ⁿ - 1 = -2, so **aₙ = -4 / (πn²)**.

Step 4: Write the series:  
f(x) = π/2 - Σ\_(n=1,3,5,...) [ 4 / (πn²) ] cos(nx)  
**f(x) = π/2 - (4/π) [ cos x + (1/3²) cos 3x + (1/5²) cos 5x + ... ]**

Step 5: Deduce the series. Put x = 0, where f(0) = 0 and cos 0 = 1:  
0 = π/2 - (4/π) [ 1 + 1/3² + 1/5² + ... ]  
(4/π) [ 1 + 1/3² + 1/5² + ... ] = π/2  
**1 + 1/3² + 1/5² + 1/7² + ... = π² / 8**  
(Hence proved)

### 3.11 Convergence, Integration, Differentiation

1. **Convergence at a jump:** If f(x) has a jump at x = x₀, the Fourier series gives the average of the left and right limits:  
   f(x₀) = [ f(x₀⁺) + f(x₀⁻) ] / 2
2. **Term-by-term integration:** Always valid, even if f(x) is not continuous. The integrated series converges faster.
3. **Term-by-term differentiation:** Valid only when f(x) is continuous everywhere and f(-π) = f(π).
4. **Parseval's Theorem:** This is energy conservation in mathematical form. The total energy of the wave equals the sum of the energies of its harmonics:  
   (1/π) ∫\_(-π)^(+π) [ f(x) ]² dx = a₀² / 2 + Σ\_(n=1)^∞ (aₙ² + bₙ²)

### 3.7 Laplace Transform of Periodic Functions

**Theorem:**  
If f(t) has period T, so that f(t + T) = f(t) for all t, then:

> **L{f(t)} = [ 1 / (1 - e^(-sT)) ] · ∫₀^T e^(-st) · f(t) dt**

**Short derivation:**  
Step 1: Split the integral into intervals of length T:  
L{f(t)} = ∫₀^T e^(-st) f(t) dt + ∫\_T^(2T) e^(-st) f(t) dt + ∫\_(2T)^(3T) e^(-st) f(t) dt + ...

Step 2: In the second integral, put t = u + T. Since f is periodic, this gives e^(-sT) ∫₀^T e^(-su) f(u) du. In the third integral, put t = u + 2T. This gives e^(-2sT) ∫₀^T e^(-su) f(u) du. And so on.

Step 3: So:  
L{f(t)} = [ 1 + e^(-sT) + e^(-2sT) + ... ] · ∫₀^T e^(-st) f(t) dt

Step 4: The bracket is an infinite geometric series with sum 1 / (1 - e^(-sT)).  
**L{f(t)} = [ 1 / (1 - e^(-sT)) ] · ∫₀^T e^(-st) · f(t) dt**  
(Hence proved)

**Solved Numerical (Sawtooth wave):**  
**Question:** Find the Laplace Transform of the sawtooth wave f(t) = (k/T) t for 0 &lt; t &lt; T, with f(t + T) = f(t).

**Solution:**  
Step 1: Use the formula: L{f(t)} = [ 1 / (1 - e^(-sT)) ] · ∫₀^T e^(-st) (k/T) t dt  

Step 2: Integrate by parts:  
∫₀^T t e^(-st) dt = - (T/s) e^(-sT) + [ -e^(-st) / s² ] from 0 to T  
= - (T/s) e^(-sT) - (e^(-sT) - 1) / s²  
= 1/s² - (T/s) e^(-sT) - (1/s²) e^(-sT)

Step 3: Put it together:  
**L{f(t)} = [ k / (T s² (1 - e^(-sT))) ] · [ 1 - e^(-sT) - sT e^(-sT) ]**

**Check:** For large s, the leading behaviour is k / (T s²). That matches the Laplace transform of (k/T) t near t = 0, since L{t} = 1/s². So the answer has the right shape.

### 3.8 Initial & Final Value Theorems

#### 1. Initial Value Theorem
If L{f(t)} = F(s), then the value at t → 0 comes from the limit s → ∞:

> **lim (t → 0) f(t) = lim (s → ∞) s · F(s)**

**Proof:**  
Step 1: L{f'(t)} = s F(s) - f(0).  
Step 2: Take s → ∞ on both sides. On the left, the integral goes to 0 because e^(-∞) = 0.  
So 0 = lim (s→∞) [ s F(s) ] - f(0).  
**Therefore f(0) = lim (s→∞) s F(s).** (Hence proved)

#### 2. Final Value Theorem
If the Laplace Transforms of f(t) and f'(t) exist, and the system is stable (all poles of F(s) are in the left half of the s-plane):

> **lim (t → ∞) f(t) = lim (s → 0) s · F(s)**

**Solved Example:**  
**Question:** Verify the Initial and Final Value Theorems for f(t) = 3 - 2 e^(-t) cos(2t).  
**Solution:**  
f(0) = 3 - 2(1)(1) = 1.  
f(∞) = 3 - 0 = 3.  
Find F(s):  
L{3} = 3/s  
L{e^(-t) cos 2t} = (s + 1) / [ (s + 1)² + 4 ]  
F(s) = 3/s - 2(s + 1) / [ (s + 1)² + 4 ]

- Initial value: lim (s→∞) s F(s) = lim (s→∞) [ 3 - 2s(s+1)/((s+1)² + 4) ] = 3 - 2 = 1 = f(0). (Verified)
- Final value: lim (s→0) s F(s) = lim (s→0) [ 3 - 2s²(s+1)/((s+1)² + 4) ] = 3 - 0 = 3 = f(∞). (Verified)

### 3.12 Fourier Transform of Gaussian Wavepacket (गॉसियन वेवपैकेट)

In quantum mechanics, the **minimum uncertainty wavepacket** of a free particle is a Gaussian:

> **f(x) = e^(-a x²)    (a &gt; 0)**

**Solved Numerical (most frequently asked Fourier question):**  
**Question:** Find the complex Fourier Transform of f(x) = e^(-ax²). Show that the transform of a Gaussian is also a Gaussian.

**Solution:**  
Step 1: Fourier Transform formula:  
F(k) = [ 1 / √(2π) ] ∫\_(-∞)^(+∞) e^(-ax²) · e^(ikx) dx

Step 2: Complete the square in the exponent:  
-ax² + ikx = -a [ x² - (ik / a) x ]  
= -a (x - ik / (2a))² - k² / (4a)

Step 3: Put it into the integral:  
F(k) = [ 1 / √(2π) ] · e^(-k²/(4a)) · ∫\_(-∞)^(+∞) e^(-a (x - ik/(2a))²) dx

Step 4: Put u = √a (x - ik / (2a)), so du = √a dx:  
∫\_(-∞)^(+∞) e^(-a (x - ik/(2a))²) dx = (1/√a) · √π = √(π / a)

Step 5: Substitute:  
F(k) = [ 1 / √(2π) ] · e^(-k²/(4a)) · √(π / a)  
**F(k) = [ 1 / √(2a) ] · e^(-k²/(4a))**  
This is again a Gaussian in k.

**Physical conclusion:**  
- A narrow wavepacket in position (large a, small Δx) becomes wide in momentum (k-space). Its spread is about 1/(4a), so Δk is large.
- This is the direct mathematical form of the **Heisenberg Uncertainty Principle, Δx · Δp ≥ ħ/2**.

**Exam tip:** Write the result in two lines. First, F(k) has the form e^(-k²/(4a)). Second, say that the width in k is inversely related to the width in x. This earns full credit for the physical conclusion.

### 3.13 Half-Range Fourier Series

When a function is given only on (0, L), we can extend it as an even or an odd function, as we choose.

1. **Half-range cosine series** (even extension, only cosine terms, bₙ = 0):

   &gt; **f(x) = a₀ / 2 + Σ\_(n=1)^∞ aₙ cos(nπx / L)**  
   &gt; a₀ = (2/L) ∫₀^L f(x) dx,  aₙ = (2/L) ∫₀^L f(x) cos(nπx / L) dx

2. **Half-range sine series** (odd extension, only sine terms, a₀ = 0 and aₙ = 0):

   &gt; **f(x) = Σ\_(n=1)^∞ bₙ sin(nπx / L)**  
   &gt; bₙ = (2/L) ∫₀^L f(x) sin(nπx / L) dx

**Solved Numerical:**  
**Question:** Find the half-range sine series of f(x) = x in (0, π).

**Solution:**  
Step 1: Only bₙ is needed (L = π):  
bₙ = (2/π) ∫₀^π x sin(nx) dx

Step 2: Integrate by parts:  
bₙ = (2/π) [ -(x cos(nx) / n) + sin(nx) / n² ] from 0 to π  
Since sin(nπ) = 0 and sin 0 = 0:  
= (2/π) [ -(π cos(nπ) / n) ]  
= -(2/n) cos(nπ) = (2/n)(-1)^(n+1)

Step 3: Write the series:  
**f(x) = 2 [ sin x - (1/2) sin 2x + (1/3) sin 3x - (1/4) sin 4x + ... ]**

## 3.14 Driven Oscillator & Resonance (Laplace Solution)

**Physical concept:**  
When an external periodic force acts on an oscillator (for example, an AC signal in a radio tuning circuit), the equation is:

> **d²y/dt² + ω₀² y = F₀ · sin(ωt)**

When the driving frequency ω equals the natural frequency ω₀, **resonance** occurs. The amplitude keeps growing. In real systems, damping keeps the amplitude finite. Here there is no damping, so the amplitude grows with time.

**Solved Numerical (exam high-yield):**  
**Question:** Solve y'' + 9y = 6 cos(3t), with y(0) = 0 and y'(0) = 0. Here ω = ω₀ = 3, so this is the resonance case.

**Solution:**  
Step 1: Take the Laplace Transform:  
[ s² Y(s) - s y(0) - y'(0) ] + 9 Y(s) = 6 · [ s / (s² + 9) ]

Step 2: Put y(0) = 0 and y'(0) = 0:  
(s² + 9) Y(s) = 6s / (s² + 9)  
**Y(s) = 6s / (s² + 9)²**

Step 3: Find the inverse. Use the multiplication-by-t rule:  
L{ t sin(3t) } = - d/ds [ 3 / (s² + 9) ] = 6s / (s² + 9)²  
So L⁻¹{ 6s / (s² + 9)² } = t sin(3t)

Step 4: The solution is **y(t) = t · sin(3t)**

**Physical analysis:**  
The amplitude is t times a sine wave. So it grows steadily with time. This is the nature of **resonance**. A bridge can break when soldiers march in step, because the steps match the bridge's natural frequency.

## 3.15 Parseval's Identity & Infinite Series

**Parseval's theorem:**  
If f(x) on [-L, L] has the Fourier series a₀/2 + Σ [ aₙ cos(nπx/L) + bₙ sin(nπx/L) ], then the mean square value of f equals the sum of the squares of its coefficients:

> **(1 / L) ∫\_(-L)^(+L) [ f(x) ]² dx = a₀² / 2 + Σ\_(n=1)^∞ (aₙ² + bₙ²)**

**Solved Numerical (10-mark classic question):**  
**Question:** Find the Fourier series of f(x) = x² in (-π, π). Then use Parseval's theorem to prove that Σ (1/n⁴) = π⁴ / 90.

**Solution:**  
Step 1: Symmetry: f(-x) = f(x), so f is **even**. Therefore **bₙ = 0**.

Step 2: Find a₀ and aₙ:  
a₀ = (2/π) ∫₀^π x² dx = (2/π)(π³/3) = 2π² / 3. So a₀/2 = π²/3.  
aₙ = (2/π) ∫₀^π x² cos(nx) dx  
By integration by parts:  
aₙ = (2/π) [ 2π(-1)ⁿ / n² ] = **4(-1)ⁿ / n²**

Step 3: Fourier series:  
x² = π²/3 + 4 Σ\_(n=1)^∞ [ (-1)ⁿ / n² ] cos(nx)

Step 4: Apply Parseval's theorem: (1/π) ∫\_(-π)^π [ f(x) ]² dx = a₀² / 2 + Σ aₙ²

Left side:  
(1/π) ∫\_(-π)^π x⁴ dx = (2/π) ∫₀^π x⁴ dx = (2/π)(π⁵ / 5) = **2π⁴ / 5**

Right side:  
a₀² / 2 = (2π²/3)² / 2 = 2π⁴ / 9  
aₙ² = 16 / n⁴

Step 5: Equate both sides:  
2π⁴ / 5 = 2π⁴ / 9 + 16 Σ (1 / n⁴)  
16 Σ (1 / n⁴) = 2π⁴ [ 1/5 - 1/9 ] = 2π⁴ (4/45) = 8π⁴ / 45  
Σ (1 / n⁴) = (8π⁴ / 45) / 16 = **π⁴ / 90**  
So **1 + 1/2⁴ + 1/3⁴ + 1/4⁴ + ... = π⁴ / 90**

**Why this is powerful:** Parseval's theorem turns an integral of x⁴ into a sum of 1/n⁴ terms. So we get the sum of an infinite series without adding its terms one by one.  
(Hence proved. A highly important result.)

## 3.16 Fourier Integral Theorem

When the period T = 2L tends to infinity (L → ∞), the Fourier series becomes an integral over continuous frequencies:

> **f(x) = (1/π) ∫₀^∞ dk ∫\_(-∞)^(+∞) f(t) · cos[ k(x - t) ] dt**

In complex form:

> **f(x) = [ 1 / √(2π) ] ∫\_(-∞)^(+∞) F(k) · e^(-ikx) dk**  
> **where F(k) = [ 1 / √(2π) ] ∫\_(-∞)^(+∞) f(x) · e^(ikx) dx**

This is the origin of the Fourier Transform and its inverse.

## 3.18 Transient Analysis in Series RLC Circuit

**Circuit data:**  
In a series RLC circuit, L = 1 H, R = 4 Ω, C = 0.2 F (so 1/C = 5), and the battery voltage is V = 10 V. The switch is closed at t = 0. Initially, q(0) = 0 and i(0) = q'(0) = 0.

**Kirchhoff's Voltage Law (KVL):**

> **L d²q/dt² + R dq/dt + (1/C) q = V(t)**  
> which gives **d²q/dt² + 4 dq/dt + 5q = 10**

**Solution by Laplace Transform:**  
Step 1: Take the Laplace Transform:  
[ s² Q(s) - s q(0) - q'(0) ] + 4 [ s Q(s) - q(0) ] + 5 Q(s) = 10 / s

Step 2: Put q(0) = 0 and q'(0) = 0:  
(s² + 4s + 5) Q(s) = 10 / s  
Q(s) = 10 / [ s (s² + 4s + 5) ]

Step 3: Partial fractions:  
10 / [ s (s² + 4s + 5) ] = A / s + (Bs + C) / (s² + 4s + 5)  
10 = A(s² + 4s + 5) + s(Bs + C)  
- Put s = 0: 10 = 5A, so A = 2  
- Coefficient of s²: 0 = A + B, so B = -2  
- Coefficient of s: 0 = 4A + C, so C = -8  

So Q(s) = 2/s - (2s + 8) / (s² + 4s + 5)

Step 4: Take the inverse. Write 2s + 8 = 2(s + 2) + 4 and s² + 4s + 5 = (s + 2)² + 1:  
Q(s) = 2/s - 2 (s + 2) / [ (s + 2)² + 1 ] - 4 / [ (s + 2)² + 1 ]  
**q(t) = 2 - 2 e^(-2t) cos t - 4 e^(-2t) sin t**

Step 5: Current i(t) = dq/dt:  
i(t) = e^(-2t) [ 4 cos t + 2 sin t + 8 sin t - 4 cos t ]  
**i(t) = 10 e^(-2t) · sin(t)  amperes**

**Physical conclusion:**  
The current starts at zero. It rises to a peak and then decays to zero because the resistor damps it. The capacitor stores a steady charge of q = 2 C. Check: as t → ∞, i(t) → 0 and q(t) → 2 C, which matches the steady state of the circuit.

## 3.19 Common Mistakes in Unit 3

1. **Sign mistake in the first shifting theorem:** For e^(at), you get F(s - a). For e^(-at), you get F(s + a).
2. **Forgetting the initial values in the derivative formula:** L{y''} = s² Y(s) - s y(0) - y'(0). Many students forget the term - s y(0). Then the whole equation is wrong.
3. **Missing factor 2 for even and odd functions:** For an even function, the integral is (2/π) ∫₀^π, not (1/π) ∫₀^π.

## Unit 3: Quick Revision Formula Sheet

- **Laplace integral:** L{f(t)} = ∫₀^∞ e^(-st) f(t) dt.
- **Standard Laplace:** L{1} = 1/s, L{tⁿ} = n!/s^(n+1), L{e^(at)} = 1/(s - a), L{sin at} = a/(s² + a²), L{cos at} = s/(s² + a²).
- **First shifting:** L{e^(at) f(t)} = F(s - a).
- **Derivatives:** L{f'(t)} = s F(s) - f(0);  L{f''(t)} = s² F(s) - s f(0) - f'(0).
- **Multiplication by t:** L{t f(t)} = - dF/ds.
- **Convolution:** L⁻¹{F(s) G(s)} = ∫₀^t f(u) g(t - u) du.
- **Dirac delta sifting:** ∫ f(x) δ(x - a) dx = f(a).
- **Dirac delta symmetry:** δ(-x) = δ(x),  δ(cx) = (1/|c|) δ(x).
- **Euler coefficients:** a₀ = (1/π) ∫ f dx, aₙ = (1/π) ∫ f cos(nx) dx, bₙ = (1/π) ∫ f sin(nx) dx.
- **Even function Fourier:** bₙ = 0.
- **Odd function Fourier:** a₀ = 0, aₙ = 0.
- **Square wave result:** (4k/π)[sin x + (1/3) sin 3x + ...], and π/4 = 1 - 1/3 + 1/5 - ...
- **Triangular wave result:** π/2 - (4/π)[cos x + (1/9) cos 3x + ...], and π²/8 = 1 + 1/9 + 1/25 + ...

## Appendix 2: Model Question Bank & PYQs (MGSU Model PYQ Bank)

### Part A: 2-Mark Compulsory Questions
1. What is the relation between the eigenvalues and the trace of a matrix?  
   **Answer:** The sum of all eigenvalues equals the trace (sum of the main diagonal elements): Σ λᵢ = Trace(A).
2. Prove that the modulus of each eigenvalue of a unitary matrix is 1.  
   **Answer:** U X = λ X, so X† U† = λ\* X†. Multiply: X† U† U X = λ\* λ X† X. Since U† U = I, we get X† X = |λ|² X† X, so |λ|² = 1 and |λ| = 1.
3. Write the Cauchy-Riemann (C-R) equations in Cartesian and polar form.  
   **Answer:** Cartesian: u\_x = v\_y, u\_y = - v\_x. Polar: u\_r = (1/r) v\_θ, v\_r = - (1/r) u\_θ.
4. Find the nature of the singularity of f(z) = (sin z)/z at z = 0.  
   **Answer:** lim (z→0) (sin z)/z = 1 (finite). So z = 0 is a **removable singularity**.
5. Find P₂(x) from the Rodrigues formula.  
   **Answer:** P₂(x) = (3x² - 1) / 2.
6. Prove that Pₙ(0) = 0 for odd n.  
   **Answer:** Pₙ(-x) = (-1)ⁿ Pₙ(x). Put x = 0: Pₙ(0) = (-1)ⁿ Pₙ(0). For odd n, (-1)ⁿ = -1. So Pₙ(0) = -Pₙ(0), which gives 2Pₙ(0) = 0, so Pₙ(0) = 0.
7. Which special function is used in the wavefunction of the quantum simple harmonic oscillator?  
   **Answer:** The Hermite polynomial Hₙ(x).
8. State two conditions for the existence of the Laplace Transform.  
   **Answer:** (i) f(t) is piecewise continuous in every finite interval. (ii) f(t) is of exponential order.
9. Write the sifting property of the Dirac delta function.  
   **Answer:** ∫ f(x) δ(x - a) dx = f(a).
10. Write Dirichlet's conditions for a Fourier series.  
    **Answer:** f(x) must be single-valued and bounded, with a finite number of discontinuities and a finite number of maxima and minima in the interval.
