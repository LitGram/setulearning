### 📋 RBSE 2026–27 Madhyamik Examination Weightage (80 Marks Theory + 20 Sessional)

| Section | Area | Marks |
|:---:|---|:---:|
| A | Reading Skills | 20 |
| B | Writing Skill (12) and Grammar (8) | 20 |
| C | Language through Literature | 40 |
| **Theory total** | | **80** |
| Sessional assessment | | 20 |
| **Overall total** | | **100** |

The Madhyamik syllabus assigns 2 marks each to determiners, tenses, subject–verb concord, and reported speech. Writing Skills (12 marks total) includes a formal letter, an analytical paragraph, and a report/essay/story/blog task, each 100–120 words; individual writing-task weights are not stated. Literature carries 40 marks: First Flight extracts 6, First Flight short/long answers 16+6, and Footprints Without Feet short/long answers 6+6. These are component weights, not chapter-specific allocations or guaranteed prompts. [Official RBSE Madhyamik Class X syllabus 2026–27, PDF pp. 3–5](https://rajeduboard.rajasthan.gov.in/anudeshika-etc/10_2027.pdf).
